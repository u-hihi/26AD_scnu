> - 목업의 "목업 전용" 표시(목업 조정판, 목업 계정, [목업: 예시 파일로 해 보기], 추정 배치 표시, 예시 데이터)는 사이트 기능이 아닙니다. 기능으로 적지 않습니다.

> **이 서비스의 구조 (02 5장, 목업)**
> - 서비스는 **학생 화면·관리자 화면·서버·데이터베이스** 네 부분으로 이루어집니다.
>   - 서버: 화면의 요청을 받아 처리하는 프로그램입니다. 직접 만듭니다.
>   - 데이터베이스: 서버가 데이터를 정리해 저장해 두는 곳입니다.
>   - API(화면과 서버가 데이터를 주고받는 창구): 두 화면은 API로 서버와 데이터를 주고받습니다.
> - 네 부분을 모두 **관리자 PC(로컬 PC: 관리자 본인의 컴퓨터)**에서 실행해 시연합니다. 학생 대상 공개(인터넷에 올리기)는 하지 않습니다(02 3.2).
> - 학생은 **로그인 없이** 공실을 봅니다. 원하면 가입·로그인해서 **내 시간표·여러 교시·여러 건물 보기**를 더 씁니다(확정, 목업 S-12~S-18).
> - 관리자 화면에는 따로 주소나 로그인 화면이 없습니다. 학생 화면의 로그인 창(S-18)에 **관리자 아이디**로 로그인하면 열립니다. 관리자 PC에서만 통과합니다. 관리자 화면은 PC만 지원합니다(확정, 목업 G-52).
> - 관리 일은 모두 관리자 화면에서 합니다. 파일 검사·변환, 공휴일 받아 오기, 메일 보내기, 방문 수 세기, 오류 기록은 서버가 합니다(02 5장).
> - **저장한 값과 업데이트한 값**
>   - 관리자가 바꾼 것은 먼저 "저장한 값"이 됩니다.
>   - 관리자가 [업데이트하기]를 눌러야 "업데이트한 값"이 되어 학생 화면에 보입니다(확정, 02 7.7 · 목업 A-17).
>   - 학생 화면은 업데이트한 값만 씁니다. 관리자의 [미리 보기]만 저장한 값을 씁니다(FR-054).
> - 관리자 PC 밖과 이어지는 것은 둘입니다. 공공 공휴일 정보 API(공공기관이 공휴일을 내주는 창구)와 메일 보내기(확인 번호 메일·문의 답장 메일)입니다(02 5장, 목업 S-14).
> - 로그인 잠시 막기·자동 로그아웃·보내기 한도 같은 **보안 관련 시간·횟수는 서버 설정 파일**(서버가 읽는 설정 값을 적어 둔 파일)에 둡니다. 관리자 화면에서는 바꾸지 않습니다(02 7.7).

## 1. 기능 목록

- **사용자** 칸의 뜻은 다음과 같습니다.
  - 학생: 로그인하지 않은 학생도 쓰는 기능입니다.
  - 공통: 학생 화면 여러 곳에 함께 쓰이는 규칙·안내입니다.
  - 로그인 학생: 가입·로그인한 학생만 쓰는 기능입니다(가입하기는 가입 전 학생).
  - 관리자: 관리자(1명)가 관리자 화면에서 하는 일입니다.
- **화면** 칸은 목업의 화면 번호입니다. S-xx는 학생 화면, A-xx는 관리자 화면입니다. 화면과의 자세한 대응은 `04_화면설계서.md`에서 다룹니다.
  - 필터: 왼쪽의 날짜·교시 고르기 구역입니다. 머리 영역: 맨 위 줄입니다. 바닥 영역: 맨 아래 줄입니다.
- **02 근거** 칸은 `02_기획서.md` v0.19의 임시 기능 번호(기능 1~11)나 절 번호입니다. 관리자 기능은 02 3.1 관리자 기능 표의 행 이름을 "3.1(행 이름)"처럼 적습니다. 02에 근거가 없으면 "02 미반영(목업 G-xx)"으로 적었습니다.
- v0.9와 비교한 점
  - FR-001~FR-030은 번호를 그대로 두고 내용을 새 구조로 고쳤습니다. 없앤 번호는 없습니다.
  - 새 기능은 FR-031~FR-056입니다.

## 2. 기능 상세

- 기능마다 **근거·입력·처리·출력·예외 상황**을 적습니다.
- 화면 배치·모양은 `04_화면설계서.md`·`05_UI디자인시스템_IA.md`에서 다룹니다. 이 문서는 동작·규칙·문구를 적습니다.
- 따옴표 안 문구는 목업에 있는 문구 그대로입니다. 안내 문구 일부는 관리자가 고칠 수 있습니다(FR-050).
- 데이터를 어떤 칸으로 저장할지는 `06_데이터모델_ERD.md`, 창구 모양은 `07_API명세서.md`, 기술 제품은 `08_아키텍처_ADR.md`에서 정합니다.
- "오늘·지금"은 모두 서버가 알려 주는 한국 시간(KST: 한국 표준시)입니다(02 7.6).

### FR-001 캠퍼스맵에서 건물 고르기

- **근거**: 02 기능 1, 7.4 / 목업 S-01, G-116·G-158·G-167·G-169·G-171
- **입력**
  - PC: 마우스로 끌어 옮기기, 마우스 휠로 확대·축소, [+] [-] 단추, 건물 누르기
  - 휴대폰: 한 손가락으로 끌어 옮기기, 두 손가락으로 확대·축소, [+] [-] 단추, 건물 누르기
- **처리**
  - 캠퍼스맵은 오픈스트리트맵(OSM: 누구나 쓸 수 있는 공개 지도 자료) 자료로 그린 지도입니다(확정, 목업 G-169).
    - 건물·도로·운동장 모양을 그리고, 학교 캠퍼스맵처럼 정문이 아래쪽이 되게 돌립니다.
    - 건물 번호·이름은 학교 캠퍼스맵 범례를 따릅니다.
    - 지도 자료만 가져와 그립니다. 외부 지도 서비스(카카오맵 등)와 GPS(위성으로 현재 위치를 알아내는 기능)는 쓰지 않습니다(02 7.4).
  - 확대·축소
    - 처음 크기는 캠퍼스맵 전체가 한 번에 보이는 크기입니다. 이보다 작게 줄일 수 없습니다.
    - 가장 크게는 처음 크기의 N배까지 확대합니다. N은 관리자가 정합니다(FR-047, 처음 값 3배).
    - [+] [-]는 한 번에 1.5배씩 확대·축소합니다. 끝에 닿은 쪽 단추는 누를 수 없습니다.
    - 지도를 옮길 때 가장자리가 가운데 구역 안쪽까지만 들어옵니다.
  - 건물 이름
    - "공과대학 1호관(D2)"처럼 이름 뒤에 건물 번호를 붙여 지도 위에 글자로 올립니다(02 7.2).
    - 글자가 겹치면 번호만 보이고, 번호도 겹치면 숨깁니다. 누를 수 있는 건물의 글자가 먼저 보입니다(확정, 목업 G-167).
    - 건물 이름 글자를 눌러도 그 건물을 누른 것과 같습니다(확정, 목업 G-171).
    - 정문·운동장 같은 곳의 이름도 지도에 보입니다. 누를 수는 없습니다.
  - 누를 수 있는 건물
    - 캠퍼스맵 영역이 있고, 관리자가 [학생이 누르기]를 켰고, 지우지 않은 건물입니다(FR-046).
    - 강의실이 없는 건물도 켜면 누를 수 있습니다(확정, 목업 G-158).
    - 꺼진 건물은 회색으로 보입니다(목업 G-116).
  - 건물을 누르면 서버가 그 건물의 조회수를 하나 셉니다(FR-019).
- **출력**
  - 로그인하지 않은 학생: 누른 건물의 층별 안내도(S-03, FR-004)로 넘어갑니다. 필터에서 고른 날짜·교시 기준입니다.
  - 로그인한 학생: 넘어가지 않고 건물을 고르기만 합니다(FR-041).
  - 고른 날짜에 건물 전체가 사용 불가인 건물은 빗금으로 보입니다. 지도 왼쪽 아래에 "빗금 = 고른 날짜에 사용 불가인 건물" 범례가 보입니다(FR-031).
- **예외 상황**
  - 꺼진 건물을 누르면 반응하지 않습니다(확정, 목업 G-167).
  - 캠퍼스맵 영역이 없는 건물(예: 공동실험실습관 C3)은 지도에서 누를 수 없습니다. 켜져 있으면 건물 목록(FR-002)에서 고릅니다(확정, 목업 G-116).
  - 필터 날짜가 오늘이고 오늘이 주말·공휴일이면 안내 창(S-07) "운영하지 않는 날입니다."를 띄우고 제자리에 머뭅니다(FR-018).
  - 필터 날짜가 오늘이고 오늘이 학기 밖이면 안내 창(S-07)을 띄우고 제자리에 머뭅니다(FR-014). 둘 다 해당하면 주말·공휴일 문구를 먼저 보입니다.
  - 건물 전체가 사용 불가면 안내 창에 사유(예: "공사 중 사용금지 · 10/16까지")만 보이고 제자리에 머뭅니다(FR-031).
  - 정보를 불러오는 중이거나 불러오지 못했으면 건물을 누를 수 없습니다(FR-032).
  - 반영한 시간표가 아직 없으면 모든 건물을 누를 수 없습니다(04 E-04).

### FR-002 건물 목록에서 건물 고르기

- **근거**: 02 기능 1, 7.4 / 목업 S-02, G-116·G-158·G-160
- **입력**: [건물 목록] 탭, 목록에서 건물 하나 누르기
- **처리**
  - [학생이 누르기]가 켜져 있고 지우지 않은 건물만 보입니다(FR-046).
    - 캠퍼스맵 영역이 없는 건물·강의실이 없는 건물도 켜져 있으면 보입니다(확정, 목업 G-116·G-158).
  - 순서는 관리자가 정합니다(FR-045).
    - 처음 값은 건물 번호 순입니다. 글자(A~F) 다음 숫자 크기 순(A2 → A10)입니다(확정, 목업 A-10).
  - 이름은 "공과대학 1호관(D2)" 형식입니다.
  - "전체 건물"은 없습니다(02 3.2).
  - 건물을 누르면 서버가 그 건물의 조회수를 셉니다(FR-019).
- **출력**
  - 로그인하지 않은 학생: 층별 안내도(S-03)로 넘어갑니다. 한 건물만 고릅니다.
  - 로그인한 학생: 줄마다 고르기 칸이 보이고, 3개까지 고릅니다(FR-041).
  - 고른 날짜에 건물 전체가 사용 불가면 그 줄에 "사용 불가" 배지(작은 이름표)가 붙습니다(FR-031).
- **예외 상황**
  - 반영한 시간표가 없으면 목록 자리에 "아직 시간표가 등록되지 않았습니다"를 보입니다.
  - 오늘이 주말·공휴일·학기 밖이거나 건물 전체가 사용 불가일 때는 FR-001 예외와 같습니다.
  - 정보를 불러오지 못하면 탭과 목록 대신 FR-032 안내만 보입니다.

### FR-003 날짜·교시 필터

- **근거**: 02 기능 3, 2.1-3, 7.6 / 목업 필터 영역, G-167, 04 v0.3 결정
- **입력**
  - 날짜: 달력에서 날짜 하나를 고릅니다. [앞 달]·[다음 달] 단추로 한 달씩 넘깁니다.
  - 교시: 달력 밑의 교시 단추(1~9교시)를 고릅니다.
- **처리**
  - **처음 열었을 때 기본값**은 오늘 날짜와 지금 교시입니다(확정, 02 7.6).
    - 오늘·지금은 서버가 알려 주는 한국 시간으로 정합니다. 학생 기기의 시계와 시간대는 쓰지 않습니다(확정, 02 7.6).
    - 학생 화면은 처음 열 때와 [초기화]를 누를 때 서버에서 시각을 받습니다(02 7.6).
    - 지금 교시는 교시 시각표(FR-044)로 정합니다. 수업 시간이면 그 교시, 쉬는 시간이면 다음 교시입니다. 1교시 시작 전과 9교시 끝 뒤는 비웁니다(FR-015).
  - **고를 수 있는 날짜** = 학기 개강일~종강일 안의 평일이면서 공휴일이 아닌 날입니다(확정, 목업 필터·A-08 안내).
    - 다른 날은 흐리게 보이고 누를 수 없습니다.
    - 달은 제한 없이 넘길 수 있습니다. 처음 보이는 달은 오늘이 속한 달입니다.
    - 오늘 날짜에는 "오늘" 테두리가 있습니다. 오늘이 고를 수 없는 날이어도 기본 날짜는 오늘입니다. 이때는 흐린 모양 + "오늘" 테두리로 보입니다(확정, 목업 G-167).
  - 로그인하지 않은 학생은 교시를 **하나만** 고릅니다. 로그인한 학생은 여러 개 고릅니다(FR-040).
  - 교시 단추에는 교시 이름과 시작 시각(예: "3교시 11:00")이 보입니다. 시각은 교시 시각표를 따릅니다.
  - 오늘 이미 지난 교시도 고를 수 있습니다(02 7.6).
  - 날짜나 교시를 바꾸면 그 기준으로 화면의 공실 / 수업중이 바뀝니다(FR-012).
  - 화면을 켜 둔 채 교시가 바뀌어도 저절로 바꾸지 않습니다(02 3.2). 학생이 [초기화]를 누릅니다.
  - 휴대폰에서는 필터가 "10/1(목) · 3교시"처럼 한 줄 요약으로 접히고, 누르면 펼쳐집니다.
- **출력**: 고른 날짜·교시 기준의 캠퍼스맵·건물 목록·층별 안내도·강의실 상세. 필터 밑 안내 칸(FR-014·FR-015·FR-040)
- **예외 상황**
  - 교시를 비워 두면 공실 / 수업중 대신 "교시를 골라 주세요"를 보입니다(FR-015).
  - 10교시·야간(18:00 이후)은 고를 수 없습니다. 교시 단추는 1~9교시뿐입니다(02 3.2).
  - 공휴일 목록이 비어 있으면 주말만 막습니다. 따로 안내하지 않습니다(확정, 02 7.6).

### FR-004 층별 안내도로 공실 보기

- **근거**: 02 기능 2, 7.5 / 목업 S-03, G-130~G-141·G-158·G-167·G-171
- **입력**: 고른 건물(FR-001·FR-002), 필터의 날짜·교시, 보기 고르기, 층 바로가기 단추, 강의실 누르기
- **처리**
  - 로그인하지 않은 학생이 건물 하나를 고르면 이 화면이 열립니다. 로그인한 학생은 공실 보기(S-12, FR-041)로 봅니다.
  - 그 건물의 모든 강의실 상태를 공실 판정(FR-012)으로 정합니다.
  - **층 묶음**
    - 높은 층이 위입니다(확정, 목업 G-167).
    - 1층부터 맨 위층까지는 강의실이 없어도 묶음을 둡니다. 관리자가 적은 다른 층(지하 등)도 넣습니다(확정, 결정 메모 2026-10-05).
    - 강의실이 없는 층은 "강의실 없음"으로 보입니다(확정, 목업 G-167).
    - 층을 알 수 없는 강의실은 맨 아래 "층 정보 없음" 묶음에 모읍니다(확정, 목업 G-167). v0.9의 (확인 필요 — 사용자 판단)을 풀었습니다.
    - 관리자가 지운 강의실은 보이지 않습니다(FR-028).
  - **보기 고르기**: 건물 이름 바로 밑에 [건물 모양] / [강의실만]을 둡니다(확정, 결정 메모 2026-10-03 · 목업 G-139).
    - [건물 모양](처음 값): 위에서 내려다본 건물 모양 + 복도 + 강의실 칸입니다(확정, 목업 G-130).
      - 건물 외곽선은 캠퍼스맵 외곽선을 가장 가까운 가로·세로 방향으로 바로 세워 씁니다. 아래쪽이 정문 쪽입니다(G-131).
      - 그림 위에 "위에서 내려다본 건물 모양입니다. 캠퍼스맵처럼 아래쪽이 정문 쪽입니다."를 보입니다(G-136).
      - 그림이 화면보다 넓으면 그림만 옆으로 밀어 봅니다. 이때 "옆으로 밀면 그림의 나머지가 보입니다 →"를 보입니다(G-134). 휴대폰은 옆으로 밀기·손가락 확대로 봅니다(결정 메모 2026-10-03).
    - [강의실만]: 건물 외곽선 없이 "강의실 줄 - 복도 - 강의실 줄" 모양입니다(G-140).
    - 고른 보기는 같은 방문 동안 다른 건물로 가도 그대로입니다. [초기화]나 새로 열기를 하면 [건물 모양]으로 돌아갑니다(G-141).
  - **강의실 배치는 지금 추정입니다.** 공과대학 1호관(D2)은 ㄷ자 모양에 맞춰 놓고, 다른 건물은 같은 규칙으로 저절로 놓습니다(G-132·G-133). 사용자가 실제 층별 배치도를 주면 바꿉니다(확정, 목업 G-135·G-171). 목업의 "목업 전용 · 추정 배치" 표시는 사이트 기능이 아닙니다.
- **출력**
  - 머리 부분
    - [← 캠퍼스맵으로], 건물 이름 "공과대학 1호관(D2)", 보기 고르기
    - 기준 줄: "10/1(목) · 3교시(11:00~11:50) 기준". 교시가 없으면 "10/1(목) 기준"처럼 날짜만 보입니다.
    - 휴강·보강·시험 안내(FR-016)
    - 층 바로가기 단추(층마다, "층 정보 없음" 포함)
  - 강의실 칸: 호실 번호와 "공실" / "수업중". 모양은 색 칸 + 글자이고, 공실은 초록·수업중은 주황빛 갈색입니다(확정, 목업 G-167).
  - 사용 불가 칸은 회색 빗금 + "사용 불가"입니다(FR-031).
  - 강의실을 누르면 강의실 상세(S-04, FR-005)가 열립니다.
- **예외 상황**
  - 교시를 고르지 않았으면 안내 칸에 "교시를 골라 주세요"를 보입니다(FR-015).
  - 그 교시에 공실이 하나도 없으면 "이 시간에는 공실이 없습니다"를 보입니다. 사용 불가 강의실은 공실로 세지 않습니다(목업 G-41).
  - 관리자가 켠, 강의실이 없는 건물: [← 캠퍼스맵으로]와 건물 이름 밑에 "데이터가 없습니다." 한 줄만 보입니다. 층·강의실·보기 고르기는 없습니다(확정, 결정 메모 2026-10-05 · 목업 G-158).
  - 브라우저 [뒤로]를 누르면 캠퍼스맵(S-01)으로 돌아갑니다.
  - 학기 밖·주말·공휴일 날짜로는 이 화면에 들어올 수 없습니다(FR-001 예외).

### FR-005 강의실 상세 정보

- **근거**: 02 기능 4, 7.2 / 목업 S-04, G-58·G-61·G-168·G-171
- **입력**: 층별 안내도(S-03)나 공실 보기(S-12)에서 강의실 하나를 누름
- **처리**
  - **상태와 시각**(고른 교시 기준, FR-012)
    - 수업중이면 그 수업이 끝나는 시각입니다. 이어지는 같은 수업은 마지막 교시가 끝나는 시각입니다(예: 3·4·5교시 → 13:50).
    - 공실이면 고른 교시 뒤, 같은 날 그 강의실의 첫 수업 시작 시각입니다.
    - 폐강 수업은 수업으로 치지 않습니다.
    - 시각은 교시 시각표(FR-044)를 따릅니다.
  - **수용 인원**
    - 관리자가 학교 홈페이지 값을 적은 강의실은 그 값을 "(추정)" 없이 씁니다(확정, 목업 G-58·G-171). v0.9의 (확인 필요)를 풀었습니다.
    - 그 밖은 자동 추정값(FR-027)을 "약 N명(추정)"으로 씁니다.
- **출력**(PC는 오른쪽 패널, 휴대폰은 아래에서 올라오는 패널)
  - 건물 이름(번호), "305호 · 3층"
  - 기준 줄: "10/1(목) · 3교시(11:00~11:50) 기준"
  - 이름·값 짝으로 보입니다(확정, 결정 메모 2026-10-05 · 목업 G-168).
    - S-03에서 열면: "상태" [공실] 또는 [수업중], "시각", "수용 인원"
    - S-12에서 열면: 고른 교시마다 한 줄("3교시" — [수업중] 11:50 끝)과 맨 아래 "수용 인원"(G-61)
  - 시각 문장에는 상태 글자를 다시 쓰지 않습니다. 예: [수업중] "11:50 끝", [공실] "다음 수업 13:00 시작"(확정, 결정 메모 2026-10-05).
  - 수용 인원 값: "약 40명(추정)" 또는 "120명"
  - 휴강·보강·시험 안내(FR-016), [신고하기](FR-011), 닫기 [X]
- **예외 상황**
  - 공실인데 그날 뒤로 남은 수업이 없으면 "남은 수업 없음"입니다. 오늘이 아닌 날도 고를 수 있으므로 "오늘"을 붙이지 않습니다.
  - 수용 인원을 정할 수 없으면 "정보 없음"입니다.
  - 층을 알 수 없으면 "305호 · 층 정보 없음"처럼 보입니다.
  - 교시를 고르지 않았으면 상태·시각 대신 "교시를 골라 주세요"를 보이고, 수용 인원만 보입니다.
  - 사용 불가 강의실은 상세가 열리지 않습니다. 열려 있던 강의실이 사용 불가가 되면 닫힙니다(FR-031).

### FR-010 문의하기

- **근거**: 02 기능 7, 7.7 / 목업 S-08, G-10
- **입력**: 머리 영역 [문의하기](휴대폰은 [≡] 메뉴 안). 문의 내용(필수), 이메일(선택), 이메일 수집·이용 동의
- **처리**
  - 사이트 안 팝업(S-08)으로 엽니다. 보던 화면은 그대로입니다(확정, 02 7.7).
  - 맨 위에 "이름·학번·전화번호 같은 개인정보는 적지 마세요."를 보입니다.
  - 문의 내용: 5자 이상, 1,000자까지. 적은 글자 수가 보입니다.
  - 이메일: 선택이고 100자까지입니다. "이메일을 적지 않으면 답장을 받을 수 없습니다."를 보입니다(확정, 02 7.7).
  - 이메일을 적으면 동의 칸이 켜지고 동의가 필수가 됩니다. 동의 내용은 다음과 같습니다(확정, 목업 S-08).
    - 쓰는 곳: 문의 답장
    - 받는 항목: 이메일
    - 보관: 처리를 마치면 바로 지웁니다. 늦어도 30일 뒤에는 저절로 지웁니다.
    - 거부할 권리: 동의하지 않아도 됩니다. 이메일 없이 보낼 수 있고, 답장은 받지 못합니다.
  - [보내기]를 누르면 검사한 뒤 서버가 데이터베이스에 저장합니다(02 7.7).
  - 로그인 여부와 관계없이 보낼 수 있습니다. 문의에는 학번을 붙이지 않습니다(목업 동작).
- **출력**
  - 보내는 동안 "보내는 중…"
  - 보낸 뒤 "문의를 보냈습니다."와 "답장은 적은 이메일로 보냅니다." 또는 "이메일을 적지 않아 답장은 없습니다.", [닫기]
  - 관리자 화면 문의 목록에 "새 문의"로 들어갑니다(FR-021).
- **예외 상황**
  - 내용이 5자 미만: "5자 이상 적어 주세요."
  - 이메일 형식이 틀림: "이메일 형식이 맞지 않습니다."
  - 이메일을 적고 동의하지 않음: "이메일을 적었으면 동의해 주세요."
  - 보내기 실패: "보내지 못했습니다. 잠시 뒤 다시 보내 주세요. 적은 내용은 그대로 있습니다." 단추가 [다시 보내기]로 바뀝니다.
  - 보낸 뒤 1분 동안은 다시 보낼 수 없습니다. "0:42 뒤에 다시 보낼 수 있습니다"처럼 남은 시간을 보입니다(NFR-018).
  - 하루 보내기 한도를 넘으면 "오늘은 더 보낼 수 없습니다. 내일 다시 보내 주세요."를 보입니다(NFR-019). 문의와 신고는 따로 셉니다.
  - 적은 내용이 있는데 [취소]나 [X]를 누르면 "적은 내용이 지워집니다. 창을 닫을까요?"를 묻습니다. 단추는 [계속 쓰기] [지우고 닫기]입니다.

### FR-011 신고하기

- **근거**: 02 기능 7, 7.7 / 목업 S-09, G-40·G-63
- **입력**: 강의실 상세(S-04)의 [신고하기] 또는 머리 영역 [신고하기]. 신고 종류(필수), 기타 내용, 자세한 내용
- **처리**
  - 사이트 안 팝업(S-09)입니다(확정, 02 7.7).
  - 강의실 상세에서 열면 강의실(예: "공과대학 1호관(D2) 305호")이 저절로 들어가고 바꿀 수 없습니다. "강의실 상세에서 열어 저절로 들어갔습니다. 바꿀 수 없습니다."를 보입니다(확정, 목업 S-09). v0.9의 미리 채우기 제안값을 풀었습니다.
  - 머리 영역에서 열면 강의실 칸이 없습니다. "어느 건물·강의실인지 자세한 내용에 적어 주세요. 들어갈 수 없는 건물도 신고할 수 있습니다."를 보입니다(확정, 목업 G-63).
  - 신고 종류는 관리자가 정한 선택지(FR-051)와 맨 끝 "기타 (직접 적기)"입니다(G-40).
    - 처음 선택지: "공실로 나오는데 실제로 수업 중", "문이 잠김", "수용 인원이 틀림"(확정, 목업 A-14). v0.9의 신고 대상 제안값을 풀었습니다.
    - "기타"를 고르면 50자까지 직접 적습니다.
  - 자세한 내용은 300자까지입니다. 머리 영역에서 열면 필수, 강의실 상세에서 열면 선택입니다(G-63).
  - 신고에는 이메일 칸이 없고 답장하지 않습니다(확정, 02 7.7).
  - 서버가 데이터베이스에 저장합니다. 학번은 붙이지 않습니다(목업 동작).
- **출력**: "신고를 보냈습니다. 감사합니다." 한 줄과 [닫기](확정, 사용자 결정 2026-10-03). 관리자 화면 신고 목록에 "새 신고"로 들어갑니다(FR-021).
- **예외 상황**
  - 종류를 고르지 않음: "신고 종류를 골라 주세요."
  - 기타를 골랐는데 비어 있음: "어떤 문제인지 적어 주세요."
  - 머리 영역에서 열었는데 자세한 내용이 비어 있음: "자세한 내용을 적어 주세요."
  - 보내기 실패·1분 기다림·하루 한도·닫기 확인은 FR-010과 같습니다. 문의와 신고는 따로 셉니다.

### FR-012 공실 판정

- **근거**: 02 4장(빈 강의실·공실 / 수업중·교시), 5.1-8, 7.1-3·7, 7.2, 7.6, 7.7 / 목업 G-41·G-59
- **입력**
  - 필터의 날짜·교시(FR-003). 로그인한 학생은 고른 교시 여러 개(FR-040)
  - 서버에서 받은 업데이트한 값: 학기(FR-023), 교시 시각표(FR-044), 그 학기 수업 시간(FR-024), 폐강 수업(FR-025), 공휴일 목록(FR-030), 사용 불가 설정(FR-049)
- **교시 시각표 처음 값 (02 7.2 확정)**. 관리자가 관리자 화면에서 바꿀 수 있습니다(FR-044).
  - 1교시는 09:00에 시작합니다. 매 교시 정시에 시작해 50분 수업, 10분 쉽니다.
  - 1~9교시만 다룹니다. 야간 수업은 지원하지 않습니다.

  | 교시 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
  |---|---|---|---|---|---|---|---|---|---|
  | 시작 | 09:00 | 10:00 | 11:00 | 12:00 | 13:00 | 14:00 | 15:00 | 16:00 | 17:00 |
  | 끝 | 09:50 | 10:50 | 11:50 | 12:50 | 13:50 | 14:50 | 15:50 | 16:50 | 17:50 |

- **처리**(학생 화면이 서버에서 받은 정보로 계산합니다, 02 5.1-8)
  1. 날짜가 주말(토·일)이거나 공휴일 목록에 있으면 FR-018로 갑니다.
  2. 날짜가 개강일~종강일 밖이면 FR-014로 갑니다.
  3. 그 날짜에 걸린 사용 불가 설정이 있으면 "사용 불가"입니다. 넓은 것부터 봅니다: 건물 전체 → 층 → 강의실(FR-031).
  4. 그 요일·교시에 그 학기 시간표상 수업이 없으면 **공실**입니다.
  5. 수업이 있어도 폐강 수업이면 **공실**입니다(02 7.1-7).
  6. 그 밖에는 **수업중**입니다.
  - 1·2단계는 달력에서 막으므로 사실상 필터 날짜가 오늘일 때만 생깁니다(FR-003).
- **"지금 교시" 구하기**(FR-003 기본값, FR-006 초기화에 씀)
  - 서버가 알려 준 한국 시간과 교시 시각표로 정합니다(확정, 02 7.6).
  - 수업 시간이면 그 교시입니다(예: 10:30 → 2교시).
  - 쉬는 시간(앞 교시 끝 ~ 다음 교시 시작 전)이면 다음 교시입니다(예: 09:55 → 2교시).
  - 1교시 시작 전·9교시 끝 뒤는 FR-015 규칙을 따릅니다.
- **출력**: 강의실마다 "공실" / "수업중" / "사용 불가"
- **예외 상황**
  - 공실은 그 학기 시간표의 수업 시간으로만 판단합니다(확정, 02 7.1-3).
  - 휴강·보강·시험은 반영하지 않습니다(FR-016).
  - 시간표가 아직 없으면 "아직 시간표가 등록되지 않았습니다"를 보입니다(FR-013).

  - 학생 화면 문구 = 사유 + " 사용금지" + (종료일이 있으면 " · 10/5까지")입니다. 예: "공사 중 사용금지 · 10/5까지", "누수 점검 사용금지"(확정, 목업 G-74).
- **출력**(확정, 목업 G-59)
  - 강의실 하나: 칸이 회색 빗금 + "사용 불가"로 보입니다. 누르면 짧은 안내 띠(약 3초)로 문구만 보이고 상세로 들어가지 않습니다.
  - 층 하나: 층 이름 밑에 문구 한 줄이 보이고, 그 층 강의실은 모두 "사용 불가"입니다.
  - 건물 전체: 캠퍼스맵에서 빗금(왼쪽 아래 범례), 건물 목록에서 "사용 불가" 배지로 보입니다. 누르면 안내 창(S-07)에 문구만 보이고 제자리에 머뭅니다.
  - 공실 보기(S-12)의 작은 칸은 "×"로 보입니다(FR-041).
- **예외 상황**: 관리자가 설정을 해제하고 업데이트하면 평소대로 보입니다.

### FR-034 가입하기

- **근거**: 02 기능 9, 5.1-14, 7.7 / 목업 S-14, G-65·G-66·G-67·G-68·G-84·G-97, 결정 메모 2026-10-03
- **입력**: 로그인 창(S-18)의 [가입하기]. 동의 2개, 학번, 확인 번호, 새 비밀번호 두 번
- **처리**: 4단계(동의 → 학번 → 확인 번호 → 비밀번호)로 나눕니다. 같은 팝업 자리가 S-14로 바뀌고, 단계 표시가 보입니다.
  1. **동의**: "이용약관에 동의합니다"(필수)와 "개인정보 수집·이용에 동의합니다"(필수)를 각각 체크해야 [다음]을 누를 수 있습니다.
     - 개인정보 동의 내용(확정, 목업 S-14)
       - 쓰는 곳: 로그인, 내 시간표 저장, 계정 관리·부정 이용 대응
       - 받는 항목: 학번, 비밀번호(알아볼 수 없게 바꿔 저장), 내 시간표
       - 보관: 탈퇴하면 바로 지웁니다. 1년 동안 쓰지 않으면 지웁니다. 내 시간표는 종강하면 지웁니다.
       - 거부할 권리: 동의하지 않아도 됩니다. 로그인하지 않고 공실 보기를 쓸 수 있습니다.
     - 이용약관은 [보기]로 펼칩니다. 내용은 **(확인 필요)**(목업 G-68: 운영 단계에서 정함).
  2. **학번**: 8자리 숫자만 적습니다. 숫자가 아닌 글자는 저절로 빠집니다. 학번 칸 예시 글자는 "예: 20260000"입니다(G-97).
     - 학교 메일 주소 "학번@s.scnu.ac.kr"로 확인 번호를 보냅니다. "이 학교 메일 주소로 확인 번호를 보냅니다."를 보입니다.
     - 8자리 학번이면 누구나 확인 번호를 받습니다. 시연 메일 허용 목록은 없앴습니다(확정, 사용자 결정 2026-10-03 · 목업 G-84).
  3. **확인 번호**: 6자리 숫자입니다(확정, 목업 G-65, NFR-017).
     - "(학번)@s.scnu.ac.kr로 확인 번호를 보냈습니다. 메일이 오지 않으면 학번이 맞는지 확인해 주세요."를 보입니다.
     - 10분 동안 쓸 수 있고, 5번까지 틀릴 수 있습니다. 남은 시간이 보입니다.
     - [확인 번호 다시 받기]는 보낸 뒤 60초가 지나야 누를 수 있습니다. 남은 초가 단추에 보입니다.
     - [학번 다시 적기]로 앞 단계로 갑니다.
  4. **비밀번호**: 새 비밀번호를 두 번 적습니다(확정, 결정 메모 2026-10-03 · 목업 G-67).
     - 규칙: 8자 이상 / 영문자를 넣음 / 숫자를 넣음 / 특수기호를 넣음 / 두 칸이 같음
     - 규칙마다 맞으면 ✓가 켜집니다. 모두 맞아야 [가입하기]를 누를 수 있습니다.
     - 학번 포함 금지·흔한 비밀번호 금지 규칙은 없습니다(사용자 결정 2026-10-03).
     - [보기]로 적은 비밀번호를 볼 수 있습니다. Caps Lock이 켜져 있으면 "Caps Lock이 켜져 있습니다"를 보입니다.
  - 서버는 비밀번호를 알아볼 수 없게 바꿔 저장합니다(목업 S-14 동의 문구). 방법은 `09_보안_개인정보.md`에서 정함.
- **출력**
  - "가입했습니다. 로그인했습니다."와 "내 계정에서 내 시간표를 넣으면, 날짜를 고를 때 공강 교시가 저절로 골라집니다.", [확인]
  - 가입하면 바로 로그인한 상태가 됩니다.
- **예외 상황**
  - 학번이 8자리 숫자가 아님: "학번 8자리 숫자를 적어 주세요."
  - 이미 가입한 학번이어도 화면은 똑같이 "확인 번호를 보냈습니다"입니다. 실제 메일에는 확인 번호 대신 "이미 가입되어 있습니다" 안내가 갑니다(확정, 목업 G-66). 화면으로 가입 여부를 알아내지 못하게 하려는 것입니다.
  - 확인 번호가 틀림: "확인 번호가 맞지 않습니다. 남은 기회 N번". 5번 틀리면 "5번 틀렸습니다. 확인 번호를 다시 받아 주세요."
  - 기한이 지남: "확인 번호 기한이 지났습니다. 다시 받아 주세요."
  - 너무 많이 받음: "확인 번호를 너무 많이 받았습니다. 1시간 뒤에 다시 시도해 주세요."(NFR-018)
  - 확인 번호 메일을 보내는 방식은 `08_아키텍처_ADR.md`에서 정함.

### FR-035 학생 로그인·로그아웃

- **근거**: 02 기능 9, 2장, 7.7 / 목업 S-18, G-51~G-55·G-93·G-95, 결정 메모 2026-10-03
- **입력**: 머리 영역 [로그인] → 로그인 창(S-18). 학번(30자까지), 비밀번호(64자까지), "로그인 상태 유지"
- **처리**
  - 로그인 창은 보던 화면을 그대로 둔 채 가운데에 뜹니다. [X]나 Esc로 닫으면 보던 화면 그대로입니다(G-93).
  - 창의 제목은 "로그인", 칸은 "학번"·"비밀번호"입니다. 그 밑에 "로그인 상태 유지"와 [로그인], 맨 아래에 [가입하기]·[비밀번호 찾기]가 있습니다(G-93).
  - 첫 칸 이름은 "학번"뿐입니다. 숫자만으로 막지 않습니다. 같은 칸에 관리자 아이디도 적기 때문입니다(확정, 결정 메모 2026-10-03 · 목업 G-52).
  - 다시 열면 지난 오류 문구는 지우고, 잠시 막기 안내는 남깁니다(G-93).
  - 맞으면 로그인합니다.
    - 창을 닫습니다. 층별 안내도를 보던 중이면 캠퍼스맵으로 돌아갑니다.
    - 공강 교시를 저절로 고릅니다(FR-040).
    - 머리 영역 [로그인] 자리가 "내 계정 ▾"로 바뀝니다. 메뉴는 내 시간표 / 비밀번호 바꾸기 / 로그아웃 / 탈퇴하기입니다(G-51).
    - 종강일이 지났으면 내 시간표를 저절로 지웁니다(FR-039).
  - "로그인 상태 유지"를 체크하면 브라우저를 닫았다 열어도 로그인이 남습니다. 체크하지 않으면 브라우저를 닫을 때 로그아웃됩니다. 유지 기간과 방법은 `09_보안_개인정보.md`에서 정함.
- **출력**
  - 로그인한 상태의 학생 화면
  - 로그아웃하면 머리 영역 바로 밑에 "로그아웃했습니다." 안내 띠가 보입니다. [닫기]를 누르거나 다시 로그인하면 사라집니다(확정, 목업 G-55).
  - 로그아웃하면 공실 보기(S-12)·내 시간표(S-13)를 보던 중이면 캠퍼스맵으로 돌아가고, 필터는 오늘·지금 교시로 돌아갑니다.
- **예외 상황**
  - 칸을 비움: "학번과 비밀번호를 적어 주세요."
  - 틀림: "학번 또는 비밀번호가 맞지 않습니다." 학생·관리자에게 같은 문구입니다.
  - 5번 틀리면 로그인을 잠시 막습니다(확정, 목업 G-53, NFR-016).
    - 계정마다, 접속한 곳마다 셉니다.
    - 막힌 동안 [로그인]만 누를 수 없습니다. "로그인을 잠시 막았습니다. N초 뒤에 다시 시도해 주세요."가 보입니다.
  - 정지된 계정: 비밀번호가 맞을 때만 "이 계정은 이용이 정지되었습니다. 사유: (사유). 궁금한 점은 [문의하기]로 알려 주세요."를 보이고 로그인하지 않습니다(확정, 목업 G-54).

- **예외 상황**: 비밀번호가 틀림: "비밀번호가 맞지 않습니다. (남은 기회 N번)". 5번 틀리면 FR-037과 같이 로그아웃하고 잠시 막습니다(G-91).

### FR-039 내 시간표

- **근거**: 02 기능 10, 5.1-15, 7.7 / 목업 S-13, G-62, 인테이크 결정 2026-10-01
- **입력**: 내 계정 ▾ → 내 시간표. 표의 칸 누르기, [시간표 비우기]
- **처리**
  - 표는 월~금 × 1~9교시입니다. 교시 칸에 그 교시의 시각이 보입니다(교시 시각표, FR-044).
  - 칸을 누르면 "수업"이 켜지거나 꺼지고, 바로 서버에 저장됩니다. "저장했습니다"가 보입니다(확정, 목업 G-62).
  - 과목 이름은 적지 않습니다.
  - 표 아래 "공강" 줄에 요일별 공강 교시를 보입니다. 공강 = 그날 첫 수업과 마지막 수업 사이의 빈 교시입니다.
  - [시간표 비우기]는 빨강 확인 창 "내 시간표를 모두 비울까요? 비운 시간표는 되돌릴 수 없습니다."를 거칩니다(G-62).
  - 종강일이 지나면 내 시간표를 저절로 지웁니다. 화면에 "종강일(12/18)이 지나면 내 시간표는 저절로 지워집니다."를 보입니다(확정, 인테이크 결정 2026-10-01 · 목업 S-13).
  - 관리자는 학생 시간표 내용을 볼 수 없습니다(목업 A-18).
- **출력**: 저장된 내 시간표와 공강 줄. 날짜를 고를 때 공강 교시 저절로 고르기에 씁니다(FR-040).
- **예외 상황**: 수업 칸이 하나도 없으면 [시간표 비우기]를 누를 수 없습니다.

### FR-040 여러 교시 고르기·공강 교시 저절로 고르기

- **근거**: 02 기능 3, 기능 11, 2.1-4, 7.6 / 목업 필터, G-56, 인테이크 결정 2026-10-01(공강 보기)
- **입력**: 로그인한 학생의 날짜 고르기, 교시 단추, 내 시간표(FR-039)
- **처리**
  - 교시 단추 위에 "교시를 여러 개 고를 수 있습니다"를 보입니다. 단추를 누를 때마다 켜고 끕니다.
  - 로그인할 때, [초기화]할 때, 날짜를 고를 때 그날의 공강 교시를 저절로 고릅니다(확정, 목업 G-56).
    - 그날 공강이 있으면: 공강 교시를 고르고 "내 시간표의 공강 교시(3·4교시)를 골랐습니다. 교시를 더하거나 뺄 수 있습니다."
    - 그날 수업이 없으면: 고르지 않고 "이날은 내 시간표에 수업이 없어 교시를 저절로 고르지 않았습니다."
    - 수업 사이 빈 교시가 없으면: 고르지 않고 "이날은 수업 사이에 빈 교시가 없어 교시를 저절로 고르지 않았습니다."
    - 내 시간표가 없으면: 오늘이면 지금 교시 하나를 고르고 "내 시간표를 넣으면 날짜를 고를 때 공강 교시가 저절로 골라집니다."
  - 학생이 교시를 바꾸면 이 안내는 사라집니다.
- **출력**: 고른 교시들(휴대폰 필터 요약 "3·4교시"), 필터 밑 안내
- **예외 상황**: 고른 교시가 없으면 "교시를 골라 주세요"를 보입니다.

### FR-041 여러 건물 공실 보기

- **근거**: 02 기능 1, 기능 11, 7.5, 7.7 / 목업 S-12, G-57·G-60·G-61·G-137·G-142~G-144·G-158·G-176, 결정 메모 2026-10-03, 사용자 결정 2026-10-06
- **입력**: 로그인한 학생이 캠퍼스맵·건물 목록에서 건물 누르기(3개까지), [공실 보기], 건물 탭, 강의실 누르기
- **처리**
  - 건물을 누르면 바로 들어가지 않고 고르기만 합니다. 다시 누르면 뺍니다(G-57).
    - 가운데 구역 위 띠에 "고른 건물 2/3"과 건물 이름 칩(작은 이름표, [X]로 빼기)이 보입니다.
    - 4번째 건물을 누르면 "건물은 3개까지 고를 수 있습니다" 띠가 잠깐 뜹니다.
    - 고르기 전 점검(주말·공휴일·학기 밖·건물 전체 사용 불가)은 FR-001과 같습니다.
    - 고를 때 서버가 그 건물 조회수를 1번 셉니다. [공실 보기]를 열 때나 건물 탭을 바꿀 때는 세지 않습니다(확정, 사용자 결정 2026-10-06 · 목업 G-176 · FR-019).
  - [공실 보기]를 누르면 공실 보기(S-12)가 열립니다. 고른 건물이 없으면 누를 수 없습니다.
  - **건물 탭**(확정, 결정 메모 2026-10-03 · 목업 G-142)
    - 고른 건물마다 탭을 하나씩 둡니다. 처음엔 첫 번째로 고른 건물 탭입니다.
    - 탭 이름은 "건물 이름(번호)"입니다. 탭 줄이 넓으면 옆으로 밀어 봅니다.
    - 좌우 화살표 키로 탭을 옮기면 바로 그 건물이 보입니다. Home·End는 처음·끝 탭으로 갑니다.
    - 건물을 하나만 골랐으면 탭 없이 건물 이름을 제목으로 보입니다(G-143).
    - 탭을 바꾸면 그 건물 맨 위부터 보이고, 다른 건물의 강의실 상세는 닫힙니다(G-144).
  - 층 묶음 규칙은 FR-004와 같습니다. 모양은 "강의실 줄 - 복도 - 강의실 줄"입니다(G-137).
  - 강의실 칸 안에 고른 교시마다 작은 칸을 둡니다: 교시 숫자 + 기호(공실 ○, 수업중 ●, 사용 불가 ×) + 색. 맨 위에 범례 한 줄을 둡니다(확정, 목업 G-60).
- **출력**
  - 머리 부분: [← 캠퍼스맵으로], "공실 보기 · 건물 N곳", 기준 줄 "10/1(목) · 3·4교시 기준", 휴강·보강·시험 안내(FR-016), 범례 "칸 안의 숫자는 교시", 건물 탭
  - 강의실을 누르면 강의실 상세(FR-005)에 고른 교시마다 한 줄씩 보입니다(G-61).
  - 브라우저 [뒤로]는 캠퍼스맵(S-01)으로 갑니다. 탭을 바꿔도 브라우저 기록은 늘지 않습니다(G-144).
- **예외 상황**
  - 고른 교시가 없으면 "교시를 골라 주세요"를 보입니다.
  - 고른 교시 어디에도 공실이 없으면 그 건물에 "이 시간에는 공실이 없습니다"를 보입니다.
  - 강의실이 없는 건물을 골랐으면 그 탭에 "데이터가 없습니다." 한 줄만 보입니다(확정, 결정 메모 2026-10-05 · 목업 G-158).
  - [← 캠퍼스맵으로]로 나갔다가 다시 [공실 보기]를 누르면 첫 번째 건물 탭부터 봅니다(G-144).

### FR-019 대시보드

- **근거**: 02 3.1, 5.1-12, 7.7 / 목업 A-02, G-77·G-176, 사용자 결정 2026-10-06
- **입력**
  - 학생이 사이트를 연 기록(방문)과 건물을 누른 기록(FR-001·FR-002·FR-041). 서버가 직접 세어 데이터베이스에 저장합니다(확정, 02 7.7).
  - 문의·신고의 처리 상태(FR-021), 오류 기록의 상태(FR-042), 관리자 로그인 기록(FR-022)
- **처리**
  - 방문자 수: 같은 브라우저는 하루에 한 번만 셉니다. 누구인지는 남기지 않습니다(확정, 02 7.7). 같은 브라우저를 알아보는 식별값(브라우저에 남기는 작은 기록, 예: 쿠키)의 안내·동의는 `09_보안_개인정보.md`에서 정함.
  - 건물 조회수: 건물별로 누른 횟수를 셉니다.
    - 로그인한 학생이 건물을 고를 때(FR-041)도 그 건물 조회수를 1번 셉니다(확정, 사용자 결정 2026-10-06 · 목업 G-176).
    - [공실 보기]를 열 때나 건물 탭을 바꿀 때는 다시 세지 않습니다.
- **출력**(관리자가 로그인하면 처음 보는 화면)
  - "지난 로그인 2026-09-30 17:02 · 그 뒤 관리자 계정 로그인 실패 2번"
  - 3일 안에 이메일이 저절로 지워질 문의가 있으면 "3일 안에 이메일이 저절로 지워질 문의가 N건 있습니다."와 [문의 보기]
  - 숫자 카드 4개: 오늘 방문자, 처리할 문의, 처리할 신고, 새 오류. 처리할 문의·신고·새 오류 카드를 누르면 그 목록으로 갑니다.
  - "방문자 수 · 최근 7일" 막대그래프. 마지막 날 값만 막대 위에 적고, 나머지는 마우스를 올리면 보입니다. [표로 보기]로 표도 봅니다(확정, 목업 G-77).
  - "건물 조회수 · 최근 7일" 표(건물 이름(번호), 누른 횟수)
  - 왼쪽 메뉴에도 처리 전 문의·신고 건수와 새 오류 건수가 보입니다.
- **예외 상황**
  - 건물 조회 기록이 없으면 "아직 건물 조회 기록이 없습니다", 방문자는 0으로 보입니다.

  - 배너
    - 배너는 하나뿐입니다. "배너 보이기" 켜기·끄기와 문구(한 줄, 60자까지)입니다(확정, 목업 G-76).

  - 지운 글은 바로 없어지지 않고 "삭제 예정" 줄로 남다가 업데이트 때 빠집니다(FR-055).

  - 글 지우기는 빨강 확인 창 "이 글을 지울까요?"를 거칩니다.

### FR-021 고객 대응

- **근거**: 02 3.1, 5.1-10·11, 7.7 / 목업 A-03·A-04·A-05, G-72·G-78·G-145·G-161·G-174·G-179, 결정 메모 2026-10-03·10-05, 사용자 결정 2026-10-06·10-07

    - 처리 안 한 건을 위에, 처리 완료한 건을 아래에 둡니다. 묶음 안은 기존 순서를 따릅니다. [처리 완료]를 누르면 그 줄은 아래 묶음으로 내려갑니다(확정, 결정 메모 2026-10-05 · 목업 G-161).

      - 쪽을 나누는 표는 쌓이는 목록 표(이 목록, 오류 기록, 학생 계정)뿐입니다(확정, 사용자 결정 2026-10-07 · 목업 G-179 · FR-056).
      - 쪽 번호 자리와 쪽 이동 규칙은 FR-056을 따릅니다.
    - 문의 목록 칸: 번호, 받은 일시, 내용, 답장(가능/없음), 상태(새 문의·답장 보냄·처리 완료), 처리 일시, 이메일 자동 삭제(날짜와 "N일 남음")

    - 처리 일시는 [처리 완료]를 누른 시각입니다. 처리 전이면 "-"입니다. 답장만 보낸 문의도 처리 전입니다(확정, 결정 메모 2026-10-03 · 목업 G-145).
    - 줄을 누르면 오른쪽에 상세가 열립니다.
  - **문의 상세(A-04)**
    - 받은 일시, 상태, 처리 일시, 답장 받을 이메일, 문의 내용, 보낸 답장(시각·내용)
    - 이메일은 앞 두 글자만 보이고 나머지는 *로 가립니다. 저절로 지울 날짜도 보입니다.
    - 이메일이 있고 처리 전이면 [답장 쓰기](2,000자까지)와 [답장 보내기]가 있습니다.
      - 확인 창 "답장을 보낼까요?"와 "보낸 메일은 되돌릴 수 없습니다."를 거칩니다. 단추는 파랑입니다(G-78).

  4. 폐강 파일에만 나오고 본 시간표에는 없는 강의실·정원은 강의실 목록에 더합니다. 폐강된 수업이므로 수업 시간은 넣지 않습니다(확정, 02 7.1-7).
  5. 같은 학기 폐강 파일을 다시 넣으면 이전 폐강 목록을 새 목록으로 바꿉니다.
     - 폐강 파일만 바꿔도 이번 학기 수용 인원 최댓값을 다시 계산합니다(확정, FR-027).
     - 앞 파일에만 있던 강의실은 목록에 남기고 "이번 파일에서 사라진 강의실"로 알려 줍니다(확정, FR-027).
  6. [폐강 파일 반영하기]를 누르면 확인 창 "폐강 파일을 반영할까요?"가 뜹니다. 반영한 내용은 저장한 값이고, [업데이트하기] 뒤 학생 화면에 보입니다.
- **출력**
  - "폐강 처리한 수업 14개 · 시간표에서 찾지 못한 폐강 과목 2개(그중 강의실 1개를 목록에 추가)"처럼 요약
  - 사라진 강의실·다시 추가된 강의실 목록(FR-027)
  - 폐강 수업이 있던 시간의 강의실은 학생 화면에 공실로 보입니다(FR-012).
- **예외 상황**
  - 종류가 틀림: "xlsx 파일만 올릴 수 있습니다." 크기는 FR-024와 같습니다.
  - 필요한 칸을 찾지 못함(오류): "필요한 칸(과목 코드·분반)을 찾지 못했습니다. 학교 파일 양식이 바뀌었을 수 있습니다." 반영하지 않습니다.
  - 강의실·정원 칸을 찾지 못하면 경고로 알립니다. 이 파일로는 강의실을 더하거나 수용 인원을 계산할 수 없습니다(02 7.2).
  - 학교 파일의 칸 구성이 학기마다 같은지는 파일을 받아 확인합니다 **(확인 필요)**.
  - 새 학기로 반영하면 폐강 카드는 비워집니다. 새 학기의 폐강 파일을 다시 올립니다(목업 A-07).

### FR-026 새 학기 반영 시 지난 학기 처리

- **근거**: 02 3.1, 5.1-5, 7.1-3 / 목업 A-07, G-70·G-81
- **입력**: A-07에서 "새 학기로 반영"을 고르고 적은 학기 이름·개강일·종강일과 시간표 파일
- **처리**
  - 학기 이름·날짜 검사는 FR-023과 같습니다.
  - [반영하기]를 누르면 빨강 확인 창 "새 학기(2027-1학기)로 반영할까요?"와 [지난 학기 수업 시간을 지우고 반영]이 뜹니다.
  - 지난 학기의 **수업 시간 데이터와 폐강 표시만 지웁니다**. 건물·강의실·층·수용 인원은 남깁니다(확정, 02 7.1-3).
  - 학기 정보를 새 학기로 바꿉니다(확정, 목업 G-81).
  - [업데이트하기] 전까지 학생 화면은 지난 학기 그대로입니다(G-81).
  - 공실은 매 학기 그 학기 시간표의 수업 시간으로만 판단합니다(확정, 02 7.1-3).
- **출력**: 새 학기 수업 시간만 담긴 저장한 값
- **예외 상황**
  - 지난 학기에만 나오고 새 학기 시간표에 없는 강의실도 목록에 남습니다. 수업이 없으므로 공실로 보이고, 숨기거나 따로 표시하지 않습니다(확정, 02 7.1-3).
  - 수용 인원(추정)은 남겨 둔 값과 새 학기 수강 정원 중 큰 값입니다. 관리자가 직접 적은 값은 늘 앞섭니다(FR-027·FR-028).
  - 잘못 반영했으면 [업데이트하기] 전에 [변경 버리기]로 마지막 업데이트 때로 되돌립니다(확정, 목업 G-70). 업데이트한 뒤에 되돌리는 방법은 `11_운영_배포.md`에서 정함.
  - 지난 학기가 끝나기 전에 새 학기를 반영하면, 지난 학기 남은 기간의 공실은 더 볼 수 없습니다. 반영 시점은 관리자가 정합니다.

### FR-027 강의실·층·수용 인원 자동 정리

- **근거**: 02 7.1-7, 7.2 / 목업 A-07·A-10, G-162, 결정 메모 2026-10-05
- **입력**: 시간표(FR-024), 폐강 교과목 파일(FR-025), 관리자가 직접 적은 값(FR-028), 남겨 둔 강의실 정보(FR-026)
- **처리**(서버가 함)
  - **강의실 목록**: 시간표에 나오는 강의실 코드로 만듭니다. 폐강 파일에만 나오는 강의실도 더합니다(FR-025). 두 파일에 한 번도 안 나오는 방은 수업용 강의실이 아닌 것으로 봅니다.
  - **건물·호실**: 강의실 코드의 앞부분은 건물 번호, 나머지는 호실입니다. 예: D2305 → 공과대학 1호관(D2) 305호(확정, 결정 메모 2026-10-05 · 목업 G-162).
    - 강의실 코드와 건물을 짝짓는 표는 따로 두지 않습니다. v0.9의 짝짓기 (확인 필요)를 풀었습니다.
    - 이 건물 번호는 **학교가 처음 정한 번호**입니다. 관리자가 화면에 보이는 건물 번호를 바꿔도(FR-028) 시간표 코드는 그대로 그 건물을 가리킵니다. 예: D2를 D9로 바꿔도 D2305는 그 건물 305호입니다(확정, 목업 G-162).
    - 맞는 건물이 없는 코드는 경고하고 그 줄만 뺍니다(FR-024).
  - **층**: 호실 번호로 정합니다(예: 305호 → 3층).
  - **수용 인원(추정)**: 지금까지 반영한 **모든 학기**에서 그 강의실에 잡힌 수업들의 수강 정원 중 가장 큰 값입니다(확정, 02 7.2). 같은 학기는 마지막으로 반영한 파일만 셉니다(확정).
    - 계산: **지난 학기까지의 최댓값**과 **이번 학기 최댓값** 중 큰 값을 씁니다(확정).
    - 새 학기를 반영하면, 남겨 둔 값과 새 학기 수강 정원 중 큰 값을 남깁니다(확정, FR-026). 이때 끝난 학기의 최댓값은 "지난 학기까지의 최댓값"에 넣습니다.
    - 같은 학기 파일을 다시 반영하면(예: 수강정정 기간), 이번 학기 최댓값은 **새 파일로 다시 계산**합니다(확정). 시간표 파일을 바꿨을 때와 폐강 파일만 바꿨을 때 모두 같습니다. 앞서 반영한 같은 학기 값은 남기지 않습니다(확정).
      - 예: D2 305호의 지난 학기까지 최댓값은 60명입니다. 2026-2학기 처음 반영 때는 정원 70명 수업이 잡혀 있었습니다. 정정 뒤 그 수업이 다른 방으로 옮겨져, 다시 반영한 파일의 최댓값은 40명입니다. 이때 수용 인원은 60명입니다(70명이 아님).
    - 지난 학기 수업 시간 데이터는 지우므로(FR-026), "지난 학기까지의 최댓값"은 이번 학기 값과 **따로 보관**합니다. 보관 방식은 `06_데이터모델_ERD.md`에서 정함.
    - 폐강 수업의 수강 정원도 계산에 넣습니다(확정). 본 시간표에도 나오는 강의실과 폐강 파일에만 나오는 강의실에 똑같이 적용합니다.
    - 관리자가 홈페이지 값을 적었으면 그 값을 늘 앞세웁니다(FR-028).
  - **누를 수 있는 건물의 처음 값** = 강의실이 있는 건물입니다. 그 뒤로는 관리자가 건물마다 켜고 끕니다(확정, 목업 G-116, FR-046).
- **출력**: 건물·호실·층·수용 인원이 정리된 강의실 목록(저장한 값). 관리자는 A-07 검사 결과와 A-10 [강의실] 탭에서 확인합니다.
- **예외 상황**
  - 번호로 층을 알 수 없는 강의실(예: E01 같은 글자 섞인 번호, 네 자리 번호)은 "층 미정"으로 두고 관리자에게 알립니다. A-10에 "층 미정 강의실이 N개 있습니다. 호실 번호로 층을 알 수 없는 강의실입니다. 층을 적어 주세요."를 보입니다(목업 A-10). 번호 규칙의 예외는 실제 시간표를 받아 확인합니다 **(확인 필요)**.
  - 층을 끝내 모르는 강의실은 학생 화면 맨 아래 "층 정보 없음" 묶음에 보입니다(확정, 목업 G-167).
  - 같은 학기 파일(시간표·폐강)을 다시 반영할 때, 앞 파일에만 있던 강의실은 목록에 **남깁니다**(확정). 이 강의실은 이번 파일에 수업이 없으므로 공실로 보입니다.
    - 서버는 "이번 파일에서 사라진 강의실" 목록을 알려 줍니다(확정).
    - 오타 코드로 잘못 들어간 강의실이면 관리자가 지울 수 있습니다(확정, FR-028).
  - 관리자가 지운 강의실이 다음에 반영하는 시간표·폐강 파일에 다시 나오면, 목록에 **다시 넣습니다**(확정). 새 파일에 나왔다면 실제로 쓰는 강의실이기 때문입니다.
    - 서버는 "다시 추가된 강의실" 목록을 알려 줍니다(확정).
    - 다시 넣을 때는 보관해 둔 값(관리자가 전에 적은 층·수용 인원, 지난 학기까지의 최댓값)을 되살립니다(확정).
    - 관리자가 적은 값이 앞선다는 규칙은 그대로입니다(FR-028).

### FR-028 건물·층·강의실 정보 관리

- **근거**: 02 3.1, 7.2 / 목업 A-10·A-11, G-58·G-115·G-149·G-162·G-171
- **입력**: A-10 [건물] 탭(강의실이 있는 건물), [강의실] 탭(건물을 고른 뒤), A-11 건물 표(모든 건물)
- **처리**
  - **건물 번호·이름 고치기**(확정, 목업 G-115)
    - 번호: "D2"처럼 영문 대문자 1~2자 + 숫자 1~2자입니다. 소문자는 대문자로 바꿉니다.
    - 다른 건물이나 문·운동장(예: 정문 A19)이 쓰는 번호는 쓸 수 없습니다.
    - 이름: 30자까지, 필수입니다.
    - 바꾼 값은 학생 화면(캠퍼스맵 이름표·건물 목록·층별 안내도·강의실 상세·신고 창)과 관리자 화면의 모든 표에 쓰입니다.
    - 시간표 코드와 맞추는 번호(학교가 처음 정한 번호)는 바뀌지 않습니다(FR-027).
  - [건물] 탭 칸: 건물 번호, 이름, 강의실 수, 캠퍼스맵 영역(있음/영역 없음), 상태, 관리. 영역이 없으면 [그리기]로 A-11에 갑니다.
  - **강의실 고치기**([강의실] 탭)
    - 보기: [전체] [층 미정만] [이번 파일에서 사라짐] [다시 추가됨]
    - 칸: 강의실 코드, 호실, 층((자동)/(직접)/층 미정), 수용 인원(직접 적은 홈페이지 값/약 N명(추정)/정보 없음), 표시(이번 파일에서 사라짐·다시 추가됨), 상태, 관리
    - 층: 번호로 층을 알 수 없는 강의실만 직접 적습니다(-3~30 사이 숫자). 번호로 정한 층은 고치지 않습니다(02 7.2).
    - 수용 인원: 학교 홈페이지 값을 1 이상 숫자로 적습니다. 비우면 자동 추정값을 씁니다. 적은 값이 자동 추정값보다 앞섭니다(02 7.2). 학생 화면에는 "(추정)" 없이 보입니다(확정, 목업 G-58·G-171).
    - [지우기]: 오타 코드로 잘못 들어간 강의실을 지웁니다. 빨강 확인 창 "공과대학 1호관(D2) 308호를 지울까요?"를 거칩니다. 업데이트 전까지 "삭제 예정" 줄로 남고 [되돌리기]가 있습니다(FR-055).
  - 강의실 코드와 건물을 짝짓는 표는 없습니다. A-10의 "강의실 코드 짝짓기" 탭은 없앴습니다(확정, 결정 메모 2026-10-05 · 목업 G-162).
  - 모두 저장한 값만 바꿉니다. 업데이트 뒤 학생 화면에 보입니다.
- **출력**: 고친 건물·강의실 정보. 학생 화면의 캠퍼스맵·건물 목록·층별 안내도·강의실 상세·공실 보기(FR-001·002·004·005·041)
- **예외 상황**
  - "건물 번호는 "D2"처럼 영문자와 숫자로 적어 주세요." / "이미 쓰는 번호입니다." / "이름을 적어 주세요."
  - "층은 숫자로 적어 주세요." / "수용 인원은 1 이상의 숫자로 적어 주세요."
  - 같은 학기 시간표를 다시 반영해도(덮어쓰기) 관리자가 적은 층·수용 인원은 남습니다(확정, 02 7.1-4).
  - 지운 강의실이 다음에 반영하는 파일에 다시 나오면 목록에 다시 들어가고, 전에 적은 값을 되살립니다(확정, FR-027).

### FR-029 캠퍼스맵 관리

  - **영역이 없는 건물**(예: C3)은 지도에 모양이 없으므로 건물 표의 [영역 그리기]로 고릅니다. 누르면 그 건물을 고르고 바로 그리기를 시작하며, 지도가 보이게 화면을 옮깁니다(G-155). "영역이 없는 건물" 카드는 없앴습니다(결정 메모 2026-10-03).
  - **[이동]**(확정, 결정 메모 2026-10-05 · 목업 G-156)
    - 영역 모양은 그대로 두고 자리만 옮깁니다. 지도에서 끌어서 옮깁니다(마우스·터치). 방향키로 옮기는 기능은 없습니다.
    - 지도 밖으로는 나가지 않습니다. 처음 자리는 점선으로 남고, 건물 번호표도 함께 옮겨집니다.
    - [끝내기]로 저장하고, [취소]나 Esc는 처음 자리로 돌아갑니다. 옮기지 않고 [끝내기]를 누르면 저장하지 않습니다.
    - 여러 조각인 건물(예: 도서관 C1)은 조각이 함께 움직입니다.
  - **[지우기]**: 그 건물의 캠퍼스맵 영역만 지웁니다. 건물은 남습니다(건물 자체를 지우는 것은 FR-046)(G-157).

  - **캠퍼스맵 그림 바꾸기**: PNG·JPG(흔히 쓰는 그림 파일 형식) 그림을 10MB까지 받습니다. 고르면 "그림을 바꾸면 건물 영역을 다시 맞춰 주세요."를 보이고 [그림 바꾸기 저장]으로 저장합니다(02 7.2). 처음 지도는 OSM 자료로 그린 지도입니다(확정, 목업 G-169).
  - 모두 저장한 값만 바꿉니다. [업데이트하기] 뒤 학생 화면에 보이고, [변경 버리기]로 마지막 업데이트 때로 돌아갑니다(확정, 목업 G-159).

- **입력**: [신고 종류] 탭. 선택지 추가(30자까지), 줄마다 ▲▼·[수정]·[지우기]
- **처리**
  - 처음 선택지: "공실로 나오는데 실제로 수업 중" / "문이 잠김" / "수용 인원이 틀림"(확정, 목업 A-14). 02의 "처음 값은 03 FR-011의 선택지"를 이 값으로 정했습니다.
  - "기타 (직접 적기)"는 늘 맨 끝이고 지울 수 없습니다(G-40).
  - "기타"를 빼고 7개까지 둡니다(확정, 목업 A-14). 7개가 되면 [선택지 추가]를 누를 수 없습니다.
  - 같은 글자나 "기타"는 쓸 수 없습니다.
  - 차례만 바꿔도, 글자를 고쳐도 같은 줄의 "수정 예정"으로 봅니다(G-151).
  - 지우기는 빨강 확인 창 "“문이 잠김” 선택지를 지울까요?"를 거칩니다.
  - 이미 받은 신고에는 그때 고른 글자가 그대로 남습니다.
  - 업데이트 뒤 신고 창(FR-011)에 쓰입니다.
- **출력**: 신고 창의 신고 종류 선택지
- **예외 상황**
  - "선택지를 적어 주세요." / "이미 있는 선택지입니다."
  - 지운 선택지를 되돌릴 때 이미 7개면 "선택지는 7개까지입니다." 알림만 보입니다(G-152).

### FR-052 API 인증키 관리

- **근거**: 02 3.1(API 인증키 관리), 7.6 / 목업 A-15, G-72·G-79·G-111~G-113, 결정 메모 2026-10-03
- **입력**: [인증키 추가](이름(쓰는 곳) 20자까지, 키 값), 줄마다 [바꾸기](키 값만), [지우기]
- **처리**
  - 인증키(외부 서비스를 쓸 자격을 확인하는 비밀 문자열)를 이름(쓰는 곳)으로 구별해 여러 개 둡니다. 예: "공휴일 정보"(확정, 결정 메모 2026-10-03 · 목업 G-111 · 02 3.1 API 인증키 관리).
  - 공휴일 불러오기는 이름이 "공휴일 정보"인 키를 씁니다(G-113).
  - 목록 칸: 이름, 키 값(끝 4자리만 "…a1B2"), 저장 시각, 마지막 확인(성공/실패와 시각), 관리
  - 키 값 전체는 적을 때도 보이지 않습니다. [보기] 단추가 없습니다(G-111).
  - 저장할 때 서버가 연결을 시험합니다([연결 시험하고 저장]). 실패하면 저장하지 않습니다. 무엇으로 시험할지는 `08_아키텍처_ADR.md`에서 정함(G-112).
  - 키는 서버에만 보관하고 학생 화면에 드러나지 않습니다. 보관 방법은 `09_보안_개인정보.md`에서 정함(확정, 02 7.6).
  - 추가·바꾸기·지우기는 모두 [업데이트하기] 없이 바로 적용됩니다(확정, 목업 G-72·G-112).
- **출력**: 인증키 목록, 알림 "저장했습니다." / "지웠습니다."
- **예외 상황**
  - "이름을 적어 주세요." / "같은 이름의 인증키가 이미 있습니다." / "키 값을 8자 이상 적어 주세요."
  - 연결 시험 실패: 빨강 상자 "연결 시험에 실패해 저장하지 못했습니다. 오류 기록 #000N"이 보이고, 오류 기록(종류 "인증키 확인")이 남습니다(G-79).
  - 지우기: 빨강 확인 창 "“공휴일 정보” 인증키를 지울까요?"와 "지운 키는 되돌릴 수 없습니다."를 거칩니다.
  - 키가 없을 때 공휴일 불러오기는 FR-030 예외를 따릅니다.

### FR-053 관리자 비밀번호·아이디 바꾸기

- **근거**: 02 3.1(관리자 로그인·계정), 7.7 / 목업 A-16, G-55·G-72·G-89~G-92
- **입력**: 탭 [비밀번호 바꾸기] [아이디 바꾸기]
- **처리**
  - **비밀번호 바꾸기**
    - 지금 비밀번호, 새 비밀번호를 두 번 적습니다.
    - 규칙: 8자 이상, 영문자·숫자·특수기호를 각각 하나 이상, 두 칸이 같음(확정, 02 7.7). 규칙이 다 맞아야 단추를 누를 수 있습니다.
    - 지금 비밀번호와 같으면 안 됩니다.
  - **아이디 바꾸기**(확정, 목업 G-89·G-90)
    - 지금 비밀번호, 새 아이디를 두 번 적습니다. 지금 아이디는 화면에 보이지 않습니다.
    - 규칙: 4~20자, 영문·숫자·_·-만, 학번과 같은 8자리 숫자는 안 됨, 지금 아이디와 같으면 안 됨
    - 확인 창 "관리자 아이디를 바꿀까요?"를 거칩니다.
  - 바꾸면 바로 로그아웃하고 다시 로그인합니다(G-89). 안내 띠(G-55):
    - "비밀번호가 바뀌었습니다. 새 비밀번호로 다시 로그인해 주세요."
    - "관리자 아이디가 바뀌었습니다. 새 아이디로 다시 로그인해 주세요."
  - [업데이트하기] 없이 바로 적용됩니다(G-72).
- **출력**: 로그아웃된 학생 화면과 안내 띠
- **예외 상황**
  - 지금 비밀번호를 틀리면 남은 기회를 알립니다. 5번 틀리면 로그아웃하고 로그인 잠시 막기를 겁니다(확정, 목업 G-91).
  - "학번과 같은 8자리 숫자는 관리자 아이디로 쓸 수 없습니다." / "아이디는 4~20자의 영문·숫자·_·-로 적어 주세요." / "지금 아이디와 같습니다. 다른 아이디를 적어 주세요." / "두 칸의 아이디가 같지 않습니다."
  - 오류가 나도 적은 값은 남깁니다.

### FR-054 업데이트하기·미리 보기·변경 버리기

- **근거**: 02 3.1(업데이트하기·미리 보기·변경 버리기), 4장([업데이트하기]), 7.1-5, 7.7 / 목업 A-17, G-69~G-72·G-81·G-173, 인테이크 결정 2026-10-01(단추 이름), 사용자 결정 2026-10-06
- **입력**: 관리자 화면 머리 영역의 [미리 보기] [변경 버리기] [업데이트하기]
- **처리**
  - 머리 영역에 "업데이트 안 한 변경 N건 · 마지막 업데이트 2026-09-15 14:30"이 늘 보입니다. N은 저장한 값과 업데이트한 값이 다른 **종류**의 수입니다.
    - 종류: 학기 정보, 교시 시각표, 시간표 파일 반영, 폐강 파일 반영, 공휴일, 공지사항, 배너, 팝업, 사용 불가 설정, 출처·안내 문구, 신고 종류, 건물 목록 순서, 캠퍼스맵 최대 확대, 캠퍼스맵 건물 영역, 캠퍼스맵 그림, 누를 수 있는 건물, 지운 건물, 건물 이름, 건물 번호, 강의실 수용 인원, 강의실 층, 지운 강의실
  - 변경이 없으면 세 단추를 누를 수 없습니다(확정, 목업 G-69).
  - **[업데이트하기]**
    - 확인 창 "학생 화면에 업데이트할까요?"와 "바뀐 것: 공지사항, 사용 불가 설정"처럼 바뀐 종류를 한 줄로 보입니다. 단추는 파랑입니다(확정, 목업 G-71).
    - 누르면 저장한 값 전체가 업데이트한 값이 됩니다. 누른 시각이 마지막 업데이트 시각이자 기준 표시의 날짜입니다(확정, 02 7.1-5, FR-013).
    - 알림 "학생 화면에 업데이트했습니다."
  - **[미리 보기]**
    - 업데이트하면 학생 화면이 어떻게 보일지를 로그인하지 않은 학생 화면으로 보여 줍니다(확정, 목업 G-69).
    - 맨 위 띠에 "미리 보기 - [업데이트하기]를 누르면 학생 화면이 이렇게 보입니다. 아직 학생에게는 보이지 않습니다."와 [미리 보기 끝내기]가 있습니다.
    - 미리 보기에서는 [로그인] 단추가 숨겨집니다.
    - 출처 문구의 "[학기]"에는 저장한 학기 이름이 들어갑니다. 학생 화면은 업데이트한 학기 이름입니다(확정, 사용자 결정 2026-10-06 · 목업 G-173, FR-017).
  - **[변경 버리기]**
    - 빨강 확인 창 "업데이트하지 않은 변경을 버릴까요?"와 "버린 변경은 되돌릴 수 없습니다."를 거칩니다.
    - 버리면 저장한 값 전체(파일 반영 포함)가 마지막 업데이트 때로 돌아갑니다(확정, 목업 G-70).
  - [업데이트하기]와 관계없이 **바로 적용되는 것**: 학생 계정 정지·정지 풀기·삭제, 인증키, 관리자 비밀번호·아이디, 문의·신고 처리, 오류 기록 확인(확정, 목업 G-72). 학생의 내 시간표도 바로 저장됩니다(FR-039).
- **출력**: 학생 화면의 새 정보. 이미 열려 있던 학생 화면은 새로 열 때 새 정보를 받습니다(NFR-007).
- **예외 상황**
  - 업데이트에 실패하면 빨강 띠 "업데이트하지 못했습니다. 오류 기록 #000N"이 보이고, 학생 화면은 그대로입니다(FR-056).
  - 업데이트한 뒤에 되돌리는 방법은 `11_운영_배포.md`에서 정함.
  - 저장한 값과 업데이트한 값을 어떻게 나눠 보관할지는 `06_데이터모델_ERD.md`·`08_아키텍처_ADR.md`에서 정함(02 7.7).

### FR-055 업데이트 전 변경 표시·되돌리기

- **근거**: 02 3.1(업데이트하기·미리 보기·변경 버리기), 7.7 / 목업 G-148~G-152, 결정 메모 2026-10-03
- **입력**: 줄 표시가 있는 표, 삭제 예정 줄의 [되돌리기]
- **처리**
  - [업데이트하기] 전 변경을 표의 줄마다 색과 글자로 함께 알립니다(확정, 결정 메모 2026-10-03 · 목업 G-148).
    - 추가 예정(초록) / 수정 예정(노랑) / 삭제 예정(빨강, 글자에 가운데 줄)
    - 줄 왼쪽 끝에 같은 색 띠를 두고, "상태" 칸(사용 불가 설정은 "업데이트" 칸)에 꽉 찬 색 배지로 글자를 보입니다.
    - 바뀐 줄이 있는 표에만 표 위에 "업데이트 전 변경 [추가 예정] 1줄"처럼 범례 한 줄을 둡니다. 바뀌지 않은 줄에는 표시가 없습니다.
  - 줄 표시를 넣은 표: 교시 시각표(A-08), 공휴일 저장한 목록(A-09), 건물·강의실(A-10), 캠퍼스맵 건물 표(A-11), 사용 불가 설정(A-12), 공지사항·팝업(A-13), 신고 종류(A-14)(G-150)
    - 바로 적용되는 것(FR-054)에는 넣지 않습니다.
    - 출처·안내 문구와 카드 제목은 "업데이트됨"/"업데이트 전" 글자로 알립니다.
    - 건물 줄의 수정 예정은 이름·번호(A-11은 학생이 누르기까지)만 봅니다. 영역 변경은 "건물 영역" 카드 표시로 알립니다.
  - 지운 줄은 바로 사라지지 않고 "삭제 예정"으로 남다가 [업데이트하기] 때 빠집니다. 삭제 예정 줄에는 [되돌리기]만 있습니다(G-149).
  - [되돌리기]는 확인 창 없이 바로 되살리고 "되돌렸습니다."를 보입니다(G-152).
  - 팝업·신고 종류는 차례만 바꾼 줄도 수정 예정입니다. 공휴일은 날짜로 줄을 구별합니다(G-151).
  - [업데이트하기]를 누르면 모든 줄 표시가 사라집니다. [변경 버리기]를 누르면 지운 줄까지 마지막 업데이트 때로 돌아갑니다(G-149).
- **출력**: 표마다 줄 표시와 범례
- **예외 상황**: 되돌릴 수 없을 때는 알림만 보입니다(같은 건물 번호를 다른 건물이 씀, 신고 종류가 이미 7개)(G-152).

### FR-056 관리자 화면 공통 안내

- **근거**: 02 미반영 / 목업 A-90·A-92, G-01·G-06·G-08·G-71·G-79·G-83·G-110·G-174·G-179·G-181, 사용자 결정 2026-10-06·10-07, 사용자 승인 2026-10-07
- **입력**: 관리자 화면의 모든 저장·지우기·처리 동작
- **처리**
  - **확인 창(A-90)**(확정, 목업 G-71)
    - 짧은 질문 제목을 씁니다. 되돌릴 수 없을 때만 그 사실을 한 줄 덧붙입니다. 예: "처리 완료할까요?" + "이메일이 지워지며 되돌릴 수 없습니다."
    - 목록의 한 줄에서 연 창은 제목에 대상을 넣습니다. 예: "학번 20260004 계정을 삭제할까요?"
    - 지우기·버리기·해제·정지·삭제 단추는 빨강입니다. [업데이트하기]·[답장 보내기]처럼 다시 고칠 수 있거나 보내는 단추는 파랑입니다.
    - [취소]나 Esc로 닫습니다.
  - **결과 알림(A-92)**(확정, 목업 G-110)
    - 짧게 씁니다. 예: "정지했습니다."
    - 학생 화면에 보이는 변경을 저장하면 "저장했습니다. 업데이트하면 학생 화면에 보입니다."처럼 한 문장을 붙입니다. 지운 것은 "업데이트하면 학생 화면에서 빠집니다."를 붙입니다.
    - 약 4초 뒤 사라집니다.
  - **처리 중**: 누른 단추가 "처리 중…"으로 바뀌고, 그동안 다른 단추를 누를 수 없습니다.
  - **서버 오류**(확정, 목업 G-79)
    - 내용 맨 위에 빨강 띠 "(무엇)하지 못했습니다. 오류 기록 #0008"과 [오류 기록 보기], 닫기 단추를 보입니다.
    - 공휴일 불러오기와 인증키 연결 시험의 실패는 띠 대신 그 단추 아래 빨강 상자로 같은 문구 모양으로 알립니다.
    - 서버는 오류 기록을 남깁니다(FR-042).
  - **입력하던 내용 지키기**: 입력 패널이 열린 채 다른 메뉴로 가면 "저장하지 않고 다른 화면으로 갈까요?"와 "적은 내용은 사라집니다."를 묻습니다. 단추는 [취소]·[저장하지 않고 이동]입니다(목업 G-06).
  - **시각 형식**: "2026-10-01 10:42"(목업 G-08)
  - **왼쪽 메뉴**: 대시보드 / 처리할 일(문의·신고, 오류 기록, 학생 계정) / 수업 자료(시간표·폐강 파일, 학기·교시 시각표, 공휴일) / 건물·강의실(건물·강의실, 캠퍼스맵, 사용 불가 설정) / 학생 화면 글(공지·배너·팝업, 문구·신고 종류) / 설정(API 인증키, 관리자 계정)
  - **화면 크기**: PC만 지원합니다. 기준 너비 1280px이고, 좁으면 가로로 밀어 봅니다(목업 G-01).
  - **표 쪽 나누기**
    - 쪽을 나누는 표는 쌓이는 목록 표 셋뿐입니다. 문의·신고(A-03, FR-021), 오류 기록(A-06, FR-042), 학생 계정(A-18, FR-043)입니다(확정, 사용자 결정 2026-10-07 · 목업 G-179).
    - 다른 관리자 표는 나누지 않고 모든 줄을 보입니다. 건물·강의실·공휴일처럼 고치면서 한눈에 봐야 하는 표이기 때문입니다(확정, 사용자 결정 2026-10-07 · 목업 G-179).
    - 20줄씩 쪽을 나눕니다(확정, 사용자 결정 2026-10-06 · 목업 G-174).
    - "처리 안 한 건 위로" 같은 정렬은 전체에 먼저 적용한 뒤 쪽을 나눕니다(확정, 사용자 결정 2026-10-06 · 목업 G-174).
    - 쪽 번호는 표 아래 가운데에 둡니다(확정, 사용자 승인 2026-10-07 · 목업 G-181).
    - 쪽 수가 7쪽을 넘으면 첫 쪽·끝 쪽·지금 쪽과 그 앞뒤 쪽만 보이고, 사이는 "…"로 줄입니다(확정, 사용자 승인 2026-10-07 · 목업 G-181).
    - 처리해서 줄이 다른 쪽으로 옮겨 가도 지금 쪽에 머무릅니다(확정, 사용자 승인 2026-10-07 · 목업 G-181).
    - 보기(탭이나 목록을 거르는 단추. 예: [문의]·[신고] 탭, [처리 전])를 바꾸면 1쪽으로 갑니다(확정, 사용자 승인 2026-10-07 · 목업 G-181). 학생 계정(A-18)의 학번 검색도 목록을 거르는 것이라 1쪽으로 갑니다(04 2.19와 같음).
    - [오류 기록 보기]로 오류 기록(A-06)에 오면 그 줄이 있는 쪽을 엽니다(확정, 사용자 승인 2026-10-07 · 목업 G-181 · FR-042).

## 3. 비기능 요구(NFR)와 목표치(SLO)

- 숫자 목표는 모두 확정입니다. NFR-001~005, 007~010, 014, 015, 019는 이 문서가 제안한 값을 사용자가 그대로 정했습니다(사용자 결정 2026-10-06).
- 이번에는 네 부분을 모두 **관리자 PC에서 실행해 시연**합니다. 학생 대상 공개는 하지 않습니다(02 3.2). 그래서 공개해야 잴 수 있는 목표(규모·가용성·HTTPS)는 "학생 대상 공개 때 적용"으로 적었습니다.
- 예상 사용자는 **약 7,000명**이고 **동시 접속은 적습니다**(02 2장).
- 아래 표에 쓰는 말의 뜻은 다음과 같습니다.
  - **p95**: 100번 해 보면 95번은 이 시간 안에 끝난다는 뜻입니다.
  - **KST**: 한국 표준시입니다.
  - **HTTPS**: 브라우저와 서버가 주고받는 내용을 암호화하는 웹 통신 방식입니다.
  - **반응형**: 화면 크기(PC·휴대폰)에 맞춰 화면 배치가 알아서 바뀌는 것입니다.
  - **px**(픽셀): 화면을 이루는 가장 작은 점 하나입니다. 화면 너비를 잴 때 씁니다.
  - **부하 시험**: 여러 요청을 한꺼번에 보내 서버가 견디는지 보는 시험입니다.
  - **해시**: 비밀번호를 알아볼 수 없는 값으로 바꾸는 방법입니다. 바꾼 값으로는 원래 비밀번호를 알 수 없습니다.
