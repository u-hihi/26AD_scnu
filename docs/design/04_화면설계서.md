> - 이 문서에 쓰는 표시의 뜻은 03 머리말과 같습니다. 한 항목에는 표시를 하나만 씁니다.
>   - **확정**: 사용자가 정한 것입니다(02·03에서 정했거나, 이 문서를 검토하며 정함).
>   - **(확인 필요)**: 사용자 확인이 필요한 것입니다. 아직 정하지 않았거나 사실 확인이 안 된 것입니다.
>   - **제안값 — 사용자 확인 필요**: 이 문서에서 제안한 값입니다. 사용자가 확인한 뒤 확정합니다.
>   - **제안 — 목업에서 확인**: 이 문서에서 제안한 **배치**(어디에 둘지)입니다. 목업을 보고 확정합니다. 제안값의 한 종류입니다.
>   - **보류 — 목업에서 결정**: 후보만 적고 정하지 않은 것입니다. 사용자가 목업을 보고 고릅니다.
>   - **"○○에서 정함"**: 뒤 문서(05·06·08·09 등)에서 정하기로 넘긴 것입니다.

> **화면 설계의 기준**
> - **PC 화면을 기준**으로 설계합니다. 기준 너비는 **1280px**입니다. px(픽셀)는 화면을 이루는 가장 작은 점 하나이며, 화면 너비를 잴 때 씁니다.
> - 휴대폰 너비 **360px**에서도 가로 스크롤(화면을 옆으로 밀어야 보이는 것)이나 겹침이 없어야 합니다(03 NFR-015). 화면마다 휴대폰에서 달라지는 점을 한 줄씩 적었습니다.
> - **마우스 조작을 기준**으로 합니다. 키보드만으로 조작하기 같은 접근성 기능은 보류입니다(03 NFR-013, 02 3.2).
> - 사이트 안에는 **학생 화면만** 있습니다. 관리자 화면·로그인은 없습니다(03 머리말).
> - 로그인·알림·즐겨찾기·교시 범위 검색·전체 건물 검색·10교시·야간·GPS(위성으로 현재 위치를 알아내는 기능)는 범위 밖입니다(02 3.2). 이 문서에도 넣지 않았습니다.

> **이 문서에 나오는 화면 용어**
> - **화면**: 창 전체(또는 가운데 큰 구역)가 바뀌는 단위입니다.
> - **패널**: 화면 한쪽에 붙어서 열리는 칸입니다. 뒤 화면은 그대로 보입니다.
> - **팝업**: 화면 위에 따로 떠오르는 작은 창입니다.
> - **모달**: 팝업 중에서, 닫기 전까지 뒤 화면을 누를 수 없게 하는 창입니다.
> - **안내 창**: 짧은 문구 하나와 [확인] 단추만 있는 작은 팝업입니다.
> - **탭**: 누르면 같은 자리의 내용이 바뀌는 단추 모음입니다(예: [캠퍼스맵] [건물 목록]).
> - **시트 탭**: 구글 시트 파일 하나 안에 있는 여러 장 가운데 한 장입니다. 화면의 탭과는 다릅니다. 예: 공지용 구글 시트의 "공휴일" 탭.
> - **스크롤**: 마우스 휠이나 손가락으로 화면 내용을 위아래로 움직여 보는 것입니다.
> - **새 탭**: 브라우저에서 지금 보던 사이트를 그대로 두고, 옆에 새로 열리는 페이지입니다.
> - **외부 화면**: 우리 사이트가 아니라 구글폼처럼 다른 서비스가 보여 주는 화면입니다.

### 1.1 화면 이동 흐름

학생이 공실을 찾는 기본 흐름은 다음과 같습니다(확정, 02 7.5·03 FR-003).

1. S-01을 엽니다. 필터에는 오늘 날짜와 지금 교시가 이미 골라져 있습니다.
2. 필요하면 필터 달력에서 **날짜**를 고르고, 그 밑에서 **교시 하나**를 고릅니다.
3. 캠퍼스맵(S-01) 또는 건물 목록(S-02)에서 **건물 하나**를 누릅니다.
4. 층별 안내도(S-03)가 열립니다. 층별로 스크롤하며 강의실마다 공실 / 수업중을 봅니다.
5. 강의실을 누르면 강의실 상세(S-04)가 열립니다.

```
                      [초기화] (어느 화면에서든) ──────────────┐
                                                               v
 사이트 열기 ──> S-01 캠퍼스맵 <──[탭]──> S-02 건물 목록
   │                │  건물 누름             │ 건물 누름
   │ (팝업 있으면)   v                        v
   └─> S-05     S-03 층별 안내도 <────────────┘
                    │  강의실 누름     (필터 날짜가 오늘이고, 오늘이 주말·공휴일
                    v                   또는 학기 밖이면: 건물 누름 → S-07, 제자리)
                S-04 강의실 상세 ──[신고하기]──> S-09 신고 구글폼(새 탭)

 머리 영역 [문의하기] ──> S-08 문의 구글폼(새 탭)
 머리 영역 [공지사항] ──> S-10 공지사항 모음 ──[제목 누름]──> S-06 공지사항 내용
                            │ [← 캠퍼스맵으로]
                            v
                          S-01
```

- 처음 화면에서 공실을 보기까지 누르는 횟수는 **1번**(건물 누름)입니다. 날짜·교시를 바꾸면 최대 3번입니다(날짜·교시·건물). 03 NFR-014의 "3번 누르기 이내" 제안값에 맞습니다.

## 2. 화면별 설계

### 2.0 공통 구역 (S-01·S-02·S-03·S-10에 함께 보이는 부분)

S-01·S-02·S-03·S-10은 같은 틀을 씁니다. 가운데 구역의 내용만 바뀝니다. 아래 배치는 **제안 — 목업에서 확인**입니다.

- 필터 영역 밑에는 다른 칸을 두지 않습니다(확정). 필터 영역이 왼쪽 구역 전체를 씁니다.
- 공지는 B. 헤드 배너 한 줄과 S-10 공지사항 모음으로 보여 줍니다. 중요한 알림은 S-05 안내 팝업으로 띄웁니다.

**PC(1280px) 배치**

```
+---------------------------------------------------------------------------------------------+
| A. 머리 영역                                                                                |
|  순천대 공실 알리미  2026-2학기 시간표 기준 · 9/15 업데이트  [초기화] [문의하기] [공지사항] |
+---------------------------------------------------------------------------------------------+
| B. 헤드 배너 (배너가 있을 때만 보임, 한 줄)                                          [닫기] |
+-------------------------+-------------------------------------------------------------------+
| C. 필터 영역 (약 320px) | D. 가운데 구역                                                    |
|   날짜 달력             |   S-01: 캠퍼스맵                                                  |
|   교시 1~9              |   S-02: 건물 목록                                                 |
|   필터 안내 문구        |   S-03: 층별 안내도                                               |
|                         |   S-10: 공지사항 모음                                             |
+-------------------------+-------------------------------------------------------------------+
| E. 바닥 영역: 출처 표시 · 휴강·보강·시험 미반영 안내                                        |
+---------------------------------------------------------------------------------------------+
```

**휴대폰(360px)**: 한 줄로 위에서 아래로 쌓습니다. 순서는 A → B → C(접어 둔 요약 한 줄) → D → E입니다. **(제안 — 목업에서 확인)**

- **휴대폰(360px)**: 서비스 이름과 [초기화]는 첫 줄에 둡니다. [문의하기]와 [공지사항]은 오른쪽 끝의 메뉴 단추(≡) 안에 함께 넣습니다. 기준 표시는 그 밑에 작은 글씨 한 줄로 둡니다. **(제안 — 목업에서 확인)**

**초기화 동작 (FR-006, 확정)**

- 누르면 날짜는 오늘로, 교시는 지금 교시로 되돌립니다. 기본값 규칙은 C. 필터 영역과 같습니다.
- 고른 건물·층별 안내도(S-03)·강의실 상세(S-04)·공지사항 모음(S-10)을 닫고, **S-01 캠퍼스맵 첫 화면**으로 돌아갑니다.
- S-02(건물 목록)를 보고 있었어도 캠퍼스맵 탭으로 돌아갑니다. 캠퍼스맵의 위치·확대 정도도 처음 상태로 돌립니다(확정).
- 자동 새로고침은 없습니다. 이 단추를 눌렀을 때만 바뀝니다(확정).
- 초기화는 데이터 파일과 공지용 구글 시트(공지·공휴일)를 다시 받아 오지 않습니다. 팝업(S-05)도 다시 띄우지 않습니다(확정).
- 초기화는 사이트를 다시 여는 것이 아닙니다. 그래서 [닫기]로 숨긴 헤드 배너도 초기화 뒤에 다시 보이지 않습니다.

```
|             +-----------------------------------+          |
+------------------------------------------------------------+
```

- 화면 가운데에 띄웁니다. **(제안 — 목업에서 확인)**
- [X]는 오른쪽 위에 둡니다. "오늘은 그만 보기" 체크 칸은 창 밑부분에 둡니다(확정). 아래쪽 [닫기] 단추는 두지 않습니다(확정).
- **휴대폰(360px)**: 좌우에 16px씩 여백을 두고 화면 너비에 맞춥니다. 내용이 길면 팝업 안에서 스크롤합니다.

**보여 주는 항목**: 팝업 제목, 팝업 내용, "오늘은 그만 보기" 체크 칸. 시트에 어떤 칸(제목·내용·그림 등)을 둘지는 **06에서 정함**입니다(FR-020).

**버튼·입력·이동**

| 조작 | 무엇을 하나 | 표시 |
|---|---|---|
| [X] (오른쪽 위) | 팝업을 닫고 뒤 화면(S-01)을 씁니다. 팝업은 [X]를 눌러야만 닫힙니다. | 확정 |
| 팝업 바깥 어두운 곳 누름 | 반응하지 않습니다. 팝업은 그대로 떠 있습니다. | 확정 |
| "오늘은 그만 보기" 체크 | 체크한 채 [X]로 닫으면, 그날은 그 팝업을 다시 띄우지 않습니다. 체크하지 않고 닫으면 다음에 사이트를 열 때 다시 뜹니다. | 확정 |

**팝업을 띄우는 규칙**

- 사이트를 열 때마다 뜹니다. 새로 고침을 해도 다시 뜹니다(확정).
- 시트에 팝업이 여러 개 있으면 한 번에 하나씩 차례로 띄웁니다. 하나를 닫으면 다음 것이 뜹니다(확정). 띄우는 차례는 시트 칸과 함께 06에서 정합니다.
- "오늘은 그만 보기"는 **체크한 그 팝업에만** 적용합니다. 같은 날 새로 올라온 팝업은 뜹니다(확정). 그래서 팝업마다 서로 구별할 수 있어야 합니다. 구별하는 칸은 06에서 정합니다.
- "그날"은 한국 시간 날짜로 셉니다. 사이트의 다른 날짜 계산과 같습니다(03 FR-012).
- 이 기능을 쓰려면 학생 브라우저에 "이 팝업을 오늘 봤음"을 기록해야 합니다. 03에 없던 동작입니다(4.6). 기록을 저장하는 방법은 08에서 정합니다. 개인정보 관점의 검토는 09에서 정합니다.

**입력 검증**: 학생이 적어 넣는 칸이 없습니다. "오늘은 그만 보기" 체크 칸만 있습니다.

### 2.7 S-07 이용할 수 없는 날 안내

- **종류**: 안내 창
- **여는 방법**: 필터 날짜가 오늘이고, 오늘이 주말·공휴일이거나 학기 밖(방학)일 때, S-01 캠퍼스맵이나 S-02 건물 목록에서 건물을 누름
- **관련 FR**: FR-014, FR-018

**레이아웃**

```
+-- S-07 안내 창 (너비 약 320px) ----+
|  운영하지 않는 날입니다.            |
|  달력에서 평일을 골라 주세요.        |
|                          [확인]    |
+------------------------------------+
```

- 모양 후보: ① 화면 가운데 작은 안내 창 + [확인] ② 캠퍼스맵 위에 몇 초 동안 떴다가 사라지는 띠. **(제안 — 목업에서 확인, ①을 제안)** ②는 학생이 못 보고 지나칠 수 있습니다.
- **휴대폰(360px)**: 좌우 여백 16px를 두고 화면 가운데에 띄웁니다.

**보여 주는 항목**: 오늘이 어떤 날인지에 따라 문구가 다릅니다.

| 오늘 | 문구 | 관련 FR | 표시 |
|---|---|---|---|
| 주말·공휴일 | "운영하지 않는 날입니다. 달력에서 평일을 골라 주세요." | FR-018 | 확정 |
| 학기 밖(방학) | "현재 학기 수업 기간이 아닙니다. 달력에서 수업 기간 날짜를 골라 주세요." | FR-014 | 확정 |
| 주말·공휴일이면서 학기 밖 | 주말·공휴일 문구 하나만 보여 줍니다. 3.1 순서에서 운영하지 않는 날이 먼저이기 때문입니다. | FR-014, FR-018 | 확정 |

**버튼·입력·이동**: [확인]을 누르면 창이 닫히고 원래 화면(S-01 또는 S-02)에 머뭅니다. 층별 안내도로 넘어가지 않습니다(확정).

**입력 검증**: 학생이 적어 넣는 칸이 없습니다.

- 이 창은 **필터 날짜가 오늘이고, 오늘이 주말·공휴일이거나 학기 밖일 때만** 나옵니다. 다른 주말·공휴일·학기 밖 날짜는 달력에서 아예 고를 수 없기 때문입니다(FR-014, FR-018).
- 공휴일 탭을 불러오지 못하면(E-23) 사이트가 오늘이 공휴일인지 알 수 없습니다. 그래서 오늘이 공휴일이어도 이 창이 뜨지 않고 S-03으로 넘어갑니다. 오늘이 주말이거나 학기 밖이면 그대로 뜹니다.

### 2.8 S-08 문의하기 (구글폼)

- **종류**: 외부 화면(새 탭). 구글폼(구글의 무료 온라인 신청서 도구)이 보여 주는 화면입니다.
- **여는 방법**: 머리 영역의 [문의하기]
- **관련 FR**: FR-010 (보낸 내용의 처리는 FR-021)

**레이아웃**: 구글폼 기본 모양을 그대로 씁니다. 목업은 만들지 않습니다(확정).

**폼의 칸** (03 FR-010: 이메일 말고 어떤 칸을 둘지는 04에서 정함)

| 칸 | 필수 여부 | 내용 | 표시 |
|---|---|---|---|
| 문의 내용 | 필수 | 긴 글로 적는 칸입니다. | 확정 |
| 답장 받기 | 필수 | "답장을 받으시겠어요?" 예 / 아니오. "이메일을 적지 않으면 답장을 받을 수 없습니다"를 함께 적습니다. | 확정 |

**입력 검증**: 구글폼의 필수 칸 기능으로 문의 내용을 비우고 보내지 못하게 합니다. 이메일 칸은 구글폼의 "이메일 형식 확인" 기능을 켭니다(확정).

**이동**: 새 탭에서 열립니다. 보낸 뒤에는 구글폼의 "응답이 기록되었습니다" 화면이 보입니다. 사이트가 열린 원래 탭은 그대로 남습니다.

## 3. 상태·예외

- 화면마다 생길 수 있는 **특별한 상태**와 **예외 상황**을 한 표로 모았습니다.
- "문구"는 화면에 보일 말입니다. 정확한 문구가 03에 없으면 제안값으로 적었습니다.
- 번호는 한 번 붙이면 바꾸지 않습니다. 없앤 번호는 비워 둡니다(E-03은 v0.2에서 없앰).

| 번호 | 상황 | 어느 화면 | 보여 주는 방법(문구) | 관련 FR | 표시 |
|---|---|---|---|---|---|
| E-01 | 데이터 파일(시간표·강의실·학기)과 공휴일 목록(공지용 구글 시트의 "공휴일" 탭)을 불러오는 중 | S-01·S-02·S-03 | 가운데 구역에 "불러오는 중…"과 도는 표시를 보여 줍니다. 다 불러올 때까지 건물을 누를 수 없습니다. 필터는 쓸 수 있습니다. 공휴일 탭을 불러오지 못하면 E-02가 아니라 E-23을 따릅니다. | FR-012 | 확정 (03에 없음, 4.6) |

### 3.1 여러 상황이 겹칠 때 먼저 보여 줄 것

한 번에 여러 안내가 해당될 수 있습니다. 이때는 아래 순서로 **앞의 것 하나만** 보여 줍니다(확정). 순서는 03 FR-012 "처리" 1~2단계 순서를 따랐습니다.

1. E-02 데이터 파일을 불러오지 못함
2. E-04 시간표가 아직 등록되지 않음
3. E-07 운영하지 않는 날(오늘이 주말·공휴일, 건물을 누를 때 S-07)
4. E-05·E-07 수업 기간 아님(오늘이 학기 밖, 건물을 누를 때 S-07)
5. E-06 교시를 고르지 않음
6. E-11 공실 없음

- 3·4는 S-07 안내 창의 문구로 나옵니다. 둘 다 해당하면 3의 문구만 보여 줍니다.
- 3·4가 해당하면 층별 안내도로 넘어가지 않습니다. 그래서 이때는 5·6이 나오지 않습니다.
- 5·6은 S-03 안내 문구 칸에 나옵니다.
- 필터 안내 문구(2.0 C ③)는 이 순서와 따로 봅니다. 수업 시간 밖·수업 기간 아님·공휴일 불러오기 실패(E-23) 안내가 함께 해당하면 한 줄에 하나씩 모두 보여 줍니다. 줄 순서는 2.0 C ③을 따릅니다.

## 4. 화면 ↔ 기능(FR) 매핑표

- **화면** 칸: 그 기능이 쓰이는 화면 번호입니다.
- **관리자 기능(FR-019~FR-030)은 사이트 안에 화면이 없습니다.** 03에서 정적 사이트(미리 만든 화면 파일과 데이터 파일만 보여 주는 사이트)로 정했고, 관리는 외부 도구로 합니다. 그래서 "사이트 화면 없음 — ○○ 도구"로 적었습니다.
