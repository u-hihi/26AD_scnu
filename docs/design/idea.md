# 내 아이디어

- 무엇: 교내(각 대학 건물)의 빈 강의실이 있는지 알려주는 서비스
- 누구를 위해: 순천대학교 학생들
- 왜: 애매하게 공강 시간이 생겼을 때 빈 강의실을 이용할 수 있도록 도와주기 위해서
- 하고 싶은 기능:
  - 지금 빈 강의실 목록 (현재 시각 기준, 건물별)
  - 시간·건물로 검색 (예: 오늘 3~5교시, 공대 1호관)
  - 강의실 상세 정보 (수용 인원, 콘센트, 다음 수업 시작 시각 등)
  - 즐겨찾기 / 알림 (자주 쓰는 건물 저장, 공강 시간 알림)
- 이번엔 안 할 것:
  - 학교 공식 앱과 연동(또는 공식 앱에 기능 추가)
  - 모바일 앱(안드로이드/iOS) 출시 — 이번엔 모바일 웹까지만
- 아직 못 정한 것:
  - 시간표 데이터를 어디서 가져올지: 파일 업로드(운영자가 시간표 엑셀/CSV 업로드) vs 학사 시스템 연동
