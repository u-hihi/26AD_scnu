## 1. 한눈에 보는 서비스

순천대학교 학생이 지금 비어 있는 강의실을 쉽게 찾도록 도와주는 **웹 서비스**(PC 우선, 휴대폰 브라우저에서도 열림)입니다.
수업 사이에 애매하게 빈 시간(공강)이 생겨도, 학생들은 어느 강의실이 비어 있는지 알기 어렵습니다.
이 서비스는 강의 시간표를 바탕으로, 캠퍼스맵에서 건물을 고르면 층별 빈 강의실을 현재 시각 기준으로 보여 줍니다.
원하는 시간과 건물로 검색할 수 있고, 강의실의 수용 인원·다음 수업 시각 같은 정보도 함께 알려 줍니다.

## 2. 핵심 기능

| 번호 | 기능 | 쉬운 설명 |
|---|---|---|
| 1 | 캠퍼스맵에서 건물 고르기 | 위에서 내려다본 지도 모양의 캠퍼스맵을 끌어 옮기고 확대·축소하며 건물을 눌러 고릅니다(건물 목록으로도 가능). 캠퍼스맵을 무엇으로 만들지는 나중에 정함. |
| 2 | 층별 안내도로 빈 강의실 보기 | 층별 안내도로 층마다 지금(또는 고른 시간대) 빈 강의실을 보여 줍니다(그림 모양은 04·목업에서 결정). |
| 3 | 시간·건물로 검색 | "오늘 3~5교시, 공대 1호관"처럼 시간과 건물을 골라 빈 강의실을 찾습니다. |
| 4 | 강의실 상세 정보 | 수용 인원("약 N명(추정)"), 다음 수업이 시작하는 시각을 보여 줍니다. |

> 이 번호는 임시 번호입니다. 정식 기능 번호(FR-001 형식)는 `03_기능명세서.md`에서 붙입니다.

## 3. 범위

### 이번에 하는 것

- 위 핵심 기능 4개
- **웹(PC 우선)**: 브라우저에서 쓰는 웹 화면(설치하는 앱이 아님). 휴대폰 브라우저에서도 열림
- **관리자 화면**: 운영자만 관리자 로그인으로 들어가는 숨겨진 화면(시간표·폐강 교과목 파일 업로드 등)

### 이번에 하지 않는 것 (범위 밖)

- 학교 공식 앱과 연동하거나 공식 앱에 기능을 추가하는 것
- 휴대폰 전용 화면(모바일 버전)과 안드로이드·iOS 앱 (웹을 먼저 만든 뒤 검토)
- 학생 로그인·계정 기능
- 휴강·보강·시험 일정 반영 (알 수 없음)
- 알림·즐겨찾기·공강 시간 입력 (매주 같은 시간·장소라 필요성이 낮음)
- 야간 수업 시간대(18:00 이후)
- 외부 지도 서비스·GPS 현재 위치, 강의실 콘센트 정보

## 4. 결정된 것

### 시간표 데이터는 "학기 단위 파일 업로드"로 받는다

- **방식**: 운영자가 한 학기 분량의 시간표 파일(엑셀/CSV)과 최종 폐강 교과목 파일을 올립니다. 첫 데이터는 2026-2학기입니다.
- **이유**: 학교 학사 시스템은 외부에 데이터를 내주는 창구(API)가 공개되어 있지 않고, 연동하려면 학교 승인이 필요해 일정을 예측하기 어렵습니다. 파일 업로드는 학교 시스템을 건드리지 않아 가장 현실적입니다.
- **제약**: 학교에서 받을 수 있는 시간표는 "2026-2학기"처럼 **한 학기 분량만** 있습니다. 빈 강의실 찾기는 "지금 이번 학기" 정보만 있으면 되므로 문제없습니다.
- **나중 후보**: 학사 시스템 연동, 공개 시간표 페이지 자동 수집(크롤링)은 학교 허락을 받은 뒤 다음 단계에서 검토합니다.

### 이 결정 때문에 설계에 넣어야 할 것

1. **학기마다 새로 올린다.** 학기마다(2월·8월쯤) 새 파일을 올리고, 데이터에 학기 이름(예: 2026-2학기)을 붙여 지난 학기와 섞이지 않게 합니다.
2. **정정 기간에는 다시 올린다.** 수강정정이 끝날 때까지 시간표가 자주 바뀌므로, 같은 학기 파일을 다시 올리면 기존 데이터를 덮어씁니다.
3. **화면에 기준을 표시한다.** "2026-2학기 시간표 기준 · 9/15 업데이트"처럼 보여 줘서, 사용자가 정보가 최신인지 알 수 있게 합니다.
4. **학기가 아닌 기간을 처리한다.** 운영자가 파일을 올릴 때 학기 시작일·종료일을 함께 입력합니다. 방학·계절학기에는 "현재 학기 수업 기간이 아닙니다"라고 안내합니다.
5. **휴강·보강·시험 일정은 알 수 없다.** 시간표에 나오지 않고 특히 휴강은 예고 없이 생기므로, 반영하지 않고 화면에 짧게 안내합니다.
